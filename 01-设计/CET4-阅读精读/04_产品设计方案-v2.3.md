# 04 · 产品设计方案 v2.3（增量：移除导入功能）

> **本文件是 v2.3 的增量说明**。v2.3 = `04_产品设计方案-v2.2.md` **减去**下列章节，未提及的内容一律沿用 v2.2。
> 决策来源：`06_设计定稿记录-v2.3.md` 决策 #11（用户原话：「我打算砍掉我们项目的导入功能」→ 确认「彻底删（含数据库字段，已导文章丢失）」）。
> 数据核实（2026-11-08）：用户库 `article` 表 **12 行全部 `visibility='system'`，零导入文章** → 本次删除的数据损失为 0。

## 一、产品定位调整

| | v2.2 | **v2.3** |
|---|---|---|
| 内容来源 | 内置 12 篇真题 **+ 用户导入（AI 解析）** | **仅内置 12 篇真题** |
| 产品定位 | CET4 精读工具 + 自定义内容 | **CET4 真题精读器（内容固定）** |
| 导航项 | 今日 / 文章库 / 复习 / 生词本 / 记录 / 导入 / 设置（7） | 今日 / 文章库 / 复习 / 生词本 / 记录 / 设置（**6**） |

**取舍理由（留档）**：导入功能的维护成本（AI 解析三档需求、整卷多篇、题型容错、39 个 fixture、3 个门禁、约 6400 行代码）远超其使用频率；产品价值集中在「对真题的精读深度」而非「内容吞吐」。砍掉后产品更聚焦、更易维护、也更容易做到「装上就能用」。

## 四、不变的部分（明确重申）

- 12 篇内置真题与全部精读能力（六段解析 / 词卡三态 / 题目与空格 / 笔记 / 句子收藏）
- 生词本、复习计划 1-3-7-14、记录统计与连续天数
- 生词导出 PDF 词表（桌面）；Android 上按 M10 已降级为禁用+说明

- 发布链路（NSIS）、窄屏响应式（M9）、Android 兼容加固（M10）

## 五、验收口径

移除后必须满足：**没有任何用户可到达的「导入」入口**；`npm run build` / 全部 manifest 门禁 / `cargo test` 全绿；数据库能正常打开（删除字段后老库不崩）。
