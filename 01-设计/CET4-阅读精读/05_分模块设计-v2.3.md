## 二、`article.visibility` 收窄

| | v2.2 | **v2.3** |
|---|---|---|
| 取值 | `system` \| `user` | **仅 `system`** |
| 写入方 | 内置导入写 `system`；用户导入写 `user` | 仅内置导入写 `system` |
| 代码处理 | 多处 `WHERE visibility='user'` / `!= 'user'` 分支 | 分支删除；字段保留（避免迁移风险） |

**为什么不删字段**：SQLite 的 `ALTER TABLE DROP COLUMN` 有版本与约束限制（索引/视图/触发器引用会拒绝），且删字段需新写迁移 + 处理老库。字段留一个恒为 `system` 的列**零风险**，代码里不再有分支——**符合「最小改动 + 数据安全」**。
（若将来彻底清理，另立包做 `004_drop_legacy_columns.sql`。）
