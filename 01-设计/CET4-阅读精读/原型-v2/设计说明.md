## 一、方向与理由

**北极星：像纸上的批注本。**

句读的本质是「断句」——把一句长英文拆成主谓宾、从句、短语。所以界面不做卡片流的 SaaS，而做一本精读本的隐喻：

- **正文是主体**：衬线英文、18px/2.0 行高、66ch 阅读列，长时间读不累；
- **解析是旁批**：右栏 372px，用细左边框与正文分开，随点随换，不浮层、不弹窗、不遮正文；
- **成分标注是这套设计的主角**：主语蓝浅底、谓语蓝实线、宾语玫红虚线、从句左侧竖线、短语虚线下划线——这是「句读」唯一能让人一眼认出的东西。

**色板**（纸感优先，不用渐变与阴影堆叠）：纸底 `#FAF8F4` / 墨 `#1F1D1A` / 靛蓝 `#2F5D8A` / 玫红 `#A63A5B` / 陶土橘 `#B4622F`（只用于主按钮与选中词）。
**深色**：`#14141A` 底，标注色单独一组（提亮降饱和），不靠同一色值硬撑两种模式。

## 三、关键设计判断

1. **点句 → 右栏原地更换**（不做浮层/弹窗/遮正文）。旁批顶部先重述正在解析的那一句，让「我在解析哪一句」始终可见。这是独立评审点名要保留的判断。
2. **选中句与成分标注分两种记号**：选中 = 极淡底（5%）；成分 = 底纹 + 线型。避免同一种记号叠三层把正文切碎（评审第 1 条）。
3. **图例必须画出来**：解析卡下方每项都带真实样式样本（色块/线型），不再用纯文字列名字（评审第 3 条）。
4. **词有持续态**：点过的词留橙色浅底 + 下划线，词卡顶部给「词在句中」的上下文条，词高亮（评审第 4 条）。
5. **文章库按来源分组，考试类型做筛选**：一级 Tab 只有「内置 / 我导入的」，考试类型（四级/六级/其他）、年份、题型是筛选器——未来接六级、考研不会把导航撑爆。
6. **卡片等高**：标题两行截断，meta 贴底，网格节奏一致（评审第 5 条）。

---

## 四、动效

**本原型未加过渡动画**（除 hover 与主题切换的即时变化）。原因：先定结构与标注系统，动效在 React 实现阶段随组件一起做（面板切换 120ms、抽屉 200ms 缓出、词卡淡入）。这一点不要当成"已完成"。

- **评分 7.5 / 10**
- 已按其 5 条差距全部修正：① 选中句三层底纹 → 极淡底；② 深色标注失效 → 深色独立一组提亮色；③ 卡内标注过小 + 图例无样式 → 字号 15px + 图例带真实样本；④ 点词无连接 → 词持续态 + 上下文条；⑤ 卡片被长标题撑高 → 等高 + 两行截断。

## 七、应用图标（已定稿）

**用户提供的图标已采纳**：暖白圆角方形底，四条圆角横线代表文字行，第三行用蓝色并在右侧跟一个句点——既像"被标记的一行字"，也直接对应产品名「句读」。

- 源文件：`原型-v2/icon/句读-选定-1024.png`（1024×1024）
- 侧栏标识：已按同一形态用内联 SVG 重画（四线 + 高亮行 + 点），27px 下可辨，颜色取自主题变量（`--ink` 墨色 / `--accent` 陶土橘），随深浅主题自动适配
- 三版备选（A 墨点与竖线 / B 断句 / C 书签句点）保留在 `icon/` 供对比，不再使用
- **多尺寸与 .ico 尚未生成**：由 M0 任务包用 `tauri icon` 从 1024 源图一次性产出（32/128/256/512、`.ico`、Android 各密度），属目标代码区动作，调度员不代做
- 可选微调（不影响采纳）：图标里的蓝偏冷偏淡，与界面标注用的靛蓝 `#2F5D8A` 不是同一支；若要品牌色与功能色统一，只需把高亮行与句点改为靛蓝或陶土橘。当前保留用户原图配色。
