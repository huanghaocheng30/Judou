## 一、验收标准

| 编号 | 判据 |
|---|---|

| **AC4** | **完成复习顺延**：`complete_review(id,'done')` → `interval_index+1`、`next_review_at = today + [1,3,7,14][newIndex]`、`review_log` 1 行（`result='done'`、记完成前的 index）；**`index` 从 3 完成 → `status='done'` 且 `next_review_at` 置为当天（写死，不再前进）**（不再出现在到期列表）；`complete_review(id,'need_more')` → `interval_index` **不前进**、`next_review_at = 明天`、`review_log` 记 `need_more` |
| **AC5** | **复习页四态**：`#/review` 支持「无到期（空态 + 回文章库按钮）」「有到期 N 篇（列表按到期日升序，每条显示标题/到期日/第几档）」「已完成今日（`get_due_reviews` 为空但 `list_review_plans` 有 `done` 记录）」「复习中」；`data-review-empty`（`none`/`done`）/ `data-review-row` / `data-review-count` / **`data-review-today`（页面自报的 today，CDP 一律从这里读，见 B5）** 供断言 |
| **AC6** | **复习模式**：`#/article/<id>?mode=review` → 精读页照常渲染正文但**隐藏**句子「析」角标、词的笔记圆点**与生词收藏按钮**（`data-review-mode="1"` 挂在 `Reader.tsx:366` 主 section）；底部出现「完成复习 / 还需再看」；点「完成复习」→ 回 `#/review` 且该篇不再在**当天**的到期列表（顺延到未来）。**跨午夜口径（B5）**：断言只用页面 `data-review-today` 自报的 today，不做跨午夜假设 |

| **AC8** | **侧边栏角标**：`#/review` 的到期数 >0 时侧边栏「复习」项显示角标（数字 = `get_due_reviews(today).length`）；为 0 时不显示；角标**文字可读**（不是纯色块），有 `aria-label` |

## 二、字段口径（DB → Rust → IPC/TS）

| DB 列 | Rust 字段（`#[serde(rename_all="camelCase")]`） | TS |
|---|---|---|
| `review_plan.article_id` | `article_id` | `articleId` |
| `review_plan.next_review_at` | `next_review_at` | `nextReviewAt`（`YYYY-MM-DD` 字符串） |
| `review_plan.interval_index` | `interval_index` | `intervalIndex`（0~3） |
| `review_plan.status` | `status` | `status`（`active`/`paused`/`done`） |
| `review_log.result` | `result` | `result`（`done`/`need_more`） |

**日期一律 `YYYY-MM-DD` 字符串**（本地日期，前端算好传给命令），不存时间戳、不用 UTC。

## 三、改动点（D0~D8）

### D0 · `src-tauri/src/review.rs`（新增，命令实现）
- `mark_article_completed(article_id)`：事务内 ① `SELECT` 既有 `review_plan` → 有则**原样返回**（幂等）；② 无则 `INSERT INTO review_plan (article_id, next_review_at, interval_index, status, updated_at) VALUES (?, ?, 0, 'active', datetime('now'))`，`next_review_at = today+1`（**today 由前端传**或 SQL 用 `date('now','localtime','+1 day')`——二选一，**选前端传 today** 便于测试）；③ `INSERT INTO reading_record (article_id, completed, last_read_at) VALUES (?, 1, datetime('now')) ON CONFLICT(article_id) DO UPDATE SET completed=1, last_read_at=datetime('now')`
- `get_due_reviews(today)`：`SELECT ... FROM review_plan p JOIN article a ON a.id=p.article_id WHERE p.status='active' AND p.next_review_at <= ? ORDER BY p.next_review_at ASC, p.article_id ASC`
- `get_review_plan(article_id)`、`list_review_logs(article_id?)`（按 `reviewed_at DESC`）
- `list_review_plans()`：**返回全部计划**（含 `status='done'` 的），供 AC5「已完成今日」态与 AC7「重新加入复习」用——**这是 B4 的实现路径**：不依赖 `Library.tsx`（不在本包范围），复习页自己列出 done 的文章并提供重启按钮
- `complete_review(article_id, result, today)`：事务内 —— 读 plan（**不存在则报 `REVIEW_PLAN_MISSING` 契约错误码**）→ `done`：`newIndex = index+1`；`newIndex >= 4` → `status='done'`、**`next_review_at` 置为当天 `today`（写死）**；否则 `next_review_at = today + [1,3,7,14][newIndex]`。`need_more`：`newIndex = index`（不前进）、`next_review_at = 明天`（**本包新定**：04 只规定 done 的顺延，need_more 的行为由本包补充，见 01 §四 #5）。→ `UPDATE review_plan` + `INSERT review_log (article_id, reviewed_at, interval_index, result)`（`interval_index` 记**完成前**的值）
- `restart_review_plan(article_id, today)`：`status='active'`、`interval_index=0`、`next_review_at=明天`、`updated_at=now`。**本包新定**：04 只说「可手动重启」未定义复位语义，本包定为「回到四档起点」。**N5**：`review_plan.next_review_at` / `updated_at` 是 `NOT NULL` 且**无 DEFAULT**（001:191/194），故 plan 不存在时**必须走 INSERT 分支**（不能 UPDATE 空行），等价于 `mark_article_completed`
- **日期来源禁令**：**三个写路径命令（`mark_article_completed` / `complete_review` / `restart_review_plan`）都必须由前端传 `today`**，**禁止**用 SQL 的 `date('now')` 推日期（那会引入 UTC 与本地两种口径）。`datetime('now')` 只允许用于 `updated_at` / `reviewed_at` / `last_read_at` 这类「记录时刻」列。
- **红线**：只写这三表；**不写** `reading_record.last_position` / `duration_sec`
- **消费接口**：现有 `db.rs` 连接池与 `commands::CommandError`；**产出接口**：7 个命令

## 五、风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| Rust 与 TS 两套顺延规则漂移 | 前端预览与实际不一致 | Rust 为权威；TS 的 `advance` 只用于预览且**必须与 Rust 用同一组用例**（AC4 用例在两边都跑） |
| 时区/日期格式 | 「今天到期」算错 | 统一 `YYYY-MM-DD` 本地字符串、today 由前端传；`verify-review.mjs` 用固定 today 断言 |
| 复习模式隐藏笔记后用户不知道有笔记 | 少信息但符合「不看提示」目的 | 底部加一行小字「复习模式已隐藏笔记标记」 |
| 幂等没做好 → 重复点「完成本篇」导致计划被重置 | 复习计划丢失 | AC2 明确「二调不改 `next_review_at`」；事务 + `SELECT` 先行 |
| `interval_index=3` 完成后的 `next_review_at` 语义含糊 | 到期查询可能又把它捞出来 | **写死**：`status='done'` 后到期查询靠 `status` 过滤，`next_review_at` 置为当天（不再前进也不影响） |
| M2/M3 的 74+35+19 项 CDP 判据被影响 | 回归 | AC9 + 全量 CDP 回归 |

**环境事实**：Node v24.21.0 / Rust 1.99.1(msvc) / `vcvars64.bat` 已知 / WebView2 v156；CDP 用 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` + **`Browser.setWindowBounds` 设真实窗口**（不用 Emulation），收工杀进程 + 1420/9222 无残留；**dev 期间不写 `02-代码`**（vite watcher 会崩）；`cargo test` 的 doc 阶段有间歇性 rlib 解析失败（用 `--lib --bins` 兜底，项目 0 doctest）。

1. **改动形态**：**13 个文件**——Rust **3**（`review.rs` **新增** / `commands.rs` / `lib.rs`）；TS/CSS **7**（`types.ts` / `api.ts` / `review.ts` **新增** / `Review.tsx` 改 / `Reader.tsx` 改 / `App.tsx` 或 Layout 改 / `app.css` 改）；脚本 **1**（`verify-review.mjs` **新增**）；配置 **1**（`package.json`）；文档 **1**（`README.md`）。**零 schema 改动**。
