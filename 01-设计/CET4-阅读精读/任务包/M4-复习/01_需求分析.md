## 一、用户要什么（一句话）

**读完一篇能记住它，明天能按计划回头复习。** 具体：读完标记完成 → 系统排 1/3/7/14 天四档 → 到期在「复习」页出现 → 复习完顺延一档 → 四次后不再提醒（可在文章库手动重启）。

| 做 | 不做（归属） |

## 三、D-M0-1 收口裁定（本包开工前置，**必须先落**）

**问题**：`reading_record`（M0 建）列名与 `docs/C2 §4.14` 不一致（docs 用 `progress` 等，我方用 `last_position`）。

**裁定**：**以我方 `001_init.sql` 为准，不改 schema**，理由：
1. `001_init.sql` 是**已验收的冻结基线**（M0 AC1「19 表 + version=2」）；改列名要加迁移（003），而 M4 用不到那些列名差异；
2. M4 只依赖 `reading_record.completed`（判断「是否完成过」）与 `last_read_at`；这两个在两种口径下语义一致；
3. M6（记录/统计）开工时若确需 docs 口径，**在 M6 内做 003 迁移 + 映射表**，不在 M4 里预支。

**落盘位置**：本包 `03-开发协同/M4-复习/决策记录.md` #1；并在 `03-开发协同/CET4-阅读精读/产品状态.md` 债务表把 D-M0-1 标「已收口（M4，裁定见 M4 决策 #1）」。

## 四、关键设计裁定（本包建立，后续包不得推翻）

| # | 问题 | 裁定 | 依据 |
|---|---|---|---|
| 1 | 「首次标记完成」这个事件**谁产生**？M2 没实现 | **M4 自建**：精读页底部加「完成本篇」按钮 → `mark_article_completed`，**幂等**（已有 `review_plan` 则不改不重建，返回既有计划） | 04 §6.6「文章**首次**标记完成时建 `review_plan`」；M2 的 02 范围未含完成标记（现网 `reading_record` 零写入），M4 若不自建则无数据可用、包不可独立交付 |
| 2 | `reading_record.completed` 写不写？ | **写**（`completed=1`，行不存在则 insert）。它是「完成过」的唯一真相，M6 复用；M4 只写这一列 + `last_read_at`，**不写** `last_position`/`duration_sec`（归 M6） | 若只写 `review_plan` 当真相，M6 会有两处真相；写 `completed` 是 04 已设计的行为 |
| 3 | `interval_index` 语义 | **表示「已完成几次」**：新建时 0；完成一次 +1；下次间隔取 `[1,3,7,14][index]`；`index=3` 完成 → `status='done'` → **不再提醒** | 04 §6.6 逐字 |
| 4 | 「还需再看」（`result='need_more'`）怎么处理 | `review_log` 记 `need_more`；**`interval_index` 不前进**；`next_review_at = 今天+1`（明天再来） | `review_log.result` 有 `need_more` 枚举（001:202），若它不产生行为则该枚举无意义；「没记住就明天再看」是最小合理语义 |
| 5 | 复习模式怎么「复用精读页」 | URL `#/article/<id>?mode=review`：精读页读 `mode=review` 后**隐藏**句子/词的笔记标记与生词按钮（避免复习时被自己的笔记提示答案），底部换成「完成复习 / 还需再看」 | 04 §八「复习模式（复用精读页，隐藏已读标记）」；M3 已定 `Reader` 不读 query 之外的参数，`mode` 是新增且不与 M3 的 `sentence`/`token` 冲突 |
| 6 | 到期判定用哪天 | **本地日期字符串 `YYYY-MM-DD`**（与 `next_review_at` 同格式），`next_review_at <= today` 即到期；**不用 UTC、不存时间戳** | 现有表 `next_review_at TEXT`；`analysis.rs` 的 `datetime('now')` 是 UTC，但「今天到期」是用户本地概念；用 `date('now','localtime')` 或前端传 today（**本包取前端传 today**，便于测试与跨时区） |
| 7 | 侧边栏角标数据从哪来 | 复用 `get_due_reviews()` 的长度（**不新增命令**）；角标在 App 启动与路由切换时刷新 | 少一次 IPC；04 §六 只要「带角标」。**若**发现抖动成本高，可退化为「仅进复习页/今日页时刷新」并登记 |

## 五、约束

- **只写** `review_plan` / `review_log` / `reading_record.completed` 三处；**不写**解析四表、内容四表、`vocab_*`、`sentence_note`/`word_note`、`app_setting`
- **零 schema 改动**（三表 M0 已建：`review_plan:189-195` / `review_log:197-203` / `reading_record:205-211`）
- 六个冻结 `data-*` 属性名不变；M3 的 `data-vocab-state` 不复用于复习
- 正文行长 66ch、精读页居中形态（M3/TP-修复3 已定）**不动**
- 复习模式的「隐藏笔记标记」用属性（`data-review-mode`）而非删 DOM，便于 CDP 断言
