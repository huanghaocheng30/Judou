## 一、两个问题

### M4-U2（bug）· 词笔记写了但词上不出现圆点

用户原话：

> 「我直接在文章库中点击对应的单词然后记笔记，结果**还是没有对应的效果**啊，是不是复习模式的逻辑有问题啊，**在句子上记笔记倒是有**」

**已核实的事实**（调度员静态核了整条链路，**链路上每一环都写了，但运行时不出圆点**）：

| 环节 | 代码位置 | 状态 |
|---|---|---|
| 笔记保存回调 | `AnalysisPanel.tsx:354-357` `<NoteEditor targetKind="word" onSaved={(hasContent) => onNoteSaved?.("word", wordId, hasContent)} />` | 在 |
| 更新标记 | `Reader.tsx:244-261` `handleNoteSaved("word", id, hasContent)` → 改 `noteMarks.tokenIds` | 在 |
| 传到正文 | `Reader.tsx:463` `noteTokenIds={noteTokenIdSet}` → `<Sentence>` | 在 |
| 绑属性 | `Reader.tsx:108` `data-has-note={node.tokenId !== undefined && noteTokenIds.has(node.tokenId) ? "1" : undefined}` | 在 |
| tokenId 来源 | `render.ts:52/63` `tokenId: token.id` | 在 |
| CSS | `app.css:1141` `.tok[data-has-note="1"] { background-image: radial-gradient(...) }` | 在 |
| **句子侧（有用）** | `Reader.tsx:462` `hasNote={noteMarks.sentenceIds.includes(...)}` | 在 |

**所以不是「没写」，是运行时某处断了。** 未验证的怀疑方向（由开发员实测定位，不要猜）：

1. **`wordId` 与 `node.tokenId` 不是同一个值** —— `AnalysisPanel` 里 `wordId` 的定义源（`selection.wordId`? `selection.id`?）与正文 `token.id` 是否同一个 ID 空间。**这是最可疑的一条。**
2. **`onSaved` 的 `hasContent` 判断** —— 是否只在某些字段非空时才为 true；用户可能只写了「语境义」。
3. **`onSaved` 触发时机** —— 防抖保存成功后是否真的调了（用户是否等到 flush）。
4. `data-has-note` 真出现了但 CSS 没生效（`.tok` 上有没有别的 `background-*` 覆盖 —— 注意 `app.css:1724` 有 `.tok-flash`，看是否有覆盖）。

**用户怀疑「复习模式逻辑有问题」→ 不成立**：截图是普通精读页（有「加入生词本」按钮、无复习底部动作区），不是复习模式。复习模式只会**故意隐藏**标记（那是设计），普通页面必须显示。

### M4-U3（漏做功能）· 「今日」页仍是 M0 骨架占位

用户原话：

> 「另外今日页是否做完了啊？感觉一直没变啊」

**核实：没做**。`src/pages/Today.tsx` 仍是 `PagePlaceholder milestone="M0"`（截图显示「骨架占位 / 今日 / 新用户空态 → 继续精读 / 今日待复习(N) 两栏；卡片可键盘聚焦。」）。

**这是 M1 的漏账**：04 §五 M1 行要求「今日页：继续精读 + 今日待复习(N) 两栏」，M1 只建了壳，M2/M3/M4 都没补。

## 二、修复后应达到的效果

**M4-U2**：在精读页点词 → 写「我的笔记」任一字段 → 保存后**词上出现小圆点**（`data-has-note="1"`）；清空笔记 → 圆点消失。句子侧行为不变。

**M4-U3**：「今日」页两栏：
1. **继续精读** —— 最近读过的一篇（`reading_record` 按 `last_read_at DESC` 取 1 条），显示标题 + 「上次读到 MM-DD」+ 点开进精读
2. **今日待复习（N）** —— `get_due_reviews(today)`，每条可「开始复习」；为空显示「今天没有到期」
3. 两栏都空（新用户）→ 引导去文章库
4. 卡片可键盘聚焦（Tab + Enter）

## 三、不做

- 不改四档顺延、复习模式、复习页、角标
- 「继续精读」的**精确位置**（滚动到上次那句）——`reading_record.last_position` M4 裁定不写，本包**只做「最近读过哪篇」**，不做位置恢复（登记债务）
- 不做今日页的图表/连续天数（M6）
