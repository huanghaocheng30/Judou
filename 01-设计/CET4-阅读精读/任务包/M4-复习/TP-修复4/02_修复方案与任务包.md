## 一、验收标准

| 编号 | 判据 |
|---|---|
| **AC-R1** | **「接下来」段存在且正确**：复习页出现 `data-review-upcoming` 段；其行 `data-review-upcoming-row`（带 `articleId`、`nextReviewAt`）来自 `list_review_plans()` 中 `status='active' AND nextReviewAt > today` 的条目，**按 `nextReviewAt` 升序**；每行显示「相对标签 + 具体日期 + 标题 + 第 N/4 次」 |
| **AC-R2** | **与今日到期互补不重复**：同一篇文章**不得同时**出现在「今日到期」与「接下来」两段；`due ∪ upcoming` 覆盖全部 `status='active'` 计划，且交集为空 |

| **AC-R5** | **不回归**：`verify:review`（135 判据）、`verify:vocab`（180）、`verify:invoke`（例外 0）、`check-contrast`（≥38）、`verify:analysis`（274）、`npm run build`、`cargo test --lib --bins` 全绿；CDP 原 M4 的 AC5/AC6/AC7/AC8 判据一项不减；`001_init.sql` 与 `01-设计/` 零改动 |

### F1 · `src/pages/Review.tsx` 加「接下来」段
- 复用现有 `listReviewPlans()` 返回值（**已带 `title`**），前端过滤 `status === "active" && nextReviewAt > today`
- 按 `nextReviewAt` 升序排序
- 渲染在「今日到期」**之后**、「已完成」**之前**
- 行内：`formatDueLabel(nextReviewAt, today)`（已有，会输出「明天」「3 天后」）+ 日期短格式（`MM-DD`）+ 标题 + 「第 N/4 次」；`formatStepLabel` 已有
- **`data-review-upcoming`（段）/ `data-review-upcoming-row`（行，带 `data-article-id`、`data-next-review-at`）**
- **不加**「开始复习」按钮（AC-R3）
- 空态分级按 AC-R4 实现

### F2 · `src/styles/app.css` 加「接下来」样式
- 追加在复习页样式段末尾（找 `data-review-done-section` 相关规则附近）
