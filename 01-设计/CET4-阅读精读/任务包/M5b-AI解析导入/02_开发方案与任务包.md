## 一、验收标准（AC1~AC12）

| 编号 | 判据 | 证据形态 |
|---|---|---|
| **AC1** | 导入页有双 Tab：`data-import-mode="quick"` / `data-import-mode="ai"`；切到 quick 时**原快速导入 6 步全流程不回归**（粘文本→预览→剔段→改标题→确认导入→跳精读） | CDP 两档各走一遍 |
| **AC2** | AI 模式下粘原文后：显示「N 段 / M 句」，且 M = 之后入库的真实句数；`data-ai-sentence-list` 内每条含 `S编号` + 该句原文前 24 字符；批量上限 15 生效（模板里写明，超过则分批） | CDP 读数 + 门禁断言 |
| **AC3** | 粘回**完整** AI payload（每句都有解析 + 题目 + 词条）→ 覆盖率显示 `解析 M/M · 题目 x/y · 词条 n` → 入库成功 → 精读页点句出**六段式**、点词出词卡、题目区显示答案 | CDP + 入库后抽 3 句核对 |
| **AC4** | 只给**部分**句解析（如 20/M）→ 覆盖率 20/M → **仍可入库**；未覆盖句点开显示「该句暂无解析」（不是空白/报错） | CDP 两态对照 |
| **AC5** | AI 改写了原文导致 quote 匹配不上 → 该条进入 `unmatched` 列表并在界面逐条列出（含原因）→ 用户点「跳过」后可继续入库；**不得静默丢弃** | CDP + 计数断言 |
| **AC6** | `structMarkup` 的 `_`/`~` 不成对或括号不配对 → **拒收**（错误码 `AI_MARKUP_UNBALANCED`）并定位到具体句；用户选「跳过该句」后可入库 | 门禁 + CDP |
| **AC7** | 题型形态不符即拒收（`AI_TYPE_MISMATCH`）：长篇带 4 选项 / 仔细阅读缺选项 / 选词填空词库 ≠15 项或空号未被解析 | 门禁 3 组反例 |
| **AC8** | AI payload 里带 `start`/`end`/`offset`/`tokens` 一律**忽略**：入库后随机抽 5 句，`paragraph.text.slice(sentence.start, sentence.end) === sentence.text` 且每个 token 切片 === surface | 门禁（node:sqlite 直读） |
| **AC9** | **后补解析**：已入库文章（含快速导入的）「补解析」→ 再补 10 句 → 覆盖率从 20/M 变 30/M；`paragraph`/`sentence`/`token` 三表**行数与内容哈希不变**；`sentence_note`/`word_note`/`vocab_entry`/`review_plan`/`review_log`/`reading_record` 行数不变 | 门禁（前后快照对比） |
| **AC10** | 三种题型 fixture（仔细阅读 / 长篇阅读 / 选词填空）各一份原文+payload 全通过；`npm run verify:ai-import` EXIT=0 | 门禁日志 |
| **AC11** | 回归全绿：`cargo test --lib --bins`（现有 45 + 新增单测全过）、`npm run build`、`verify:invoke`（例外 0）、`verify:review`、`verify:vocab`、`verify:import-user`、`check:contrast` | 门禁日志 |
| **AC12** | 数据零触碰：并入事务只写 `article`/`paragraph`/`sentence`/`token`/`sentence_analysis`/`question`/`lexicon`；8 张用户表行数与内容不变 | 门禁（前后快照） |

## 四、风险与三问裁定

| 风险 | 缓解 |
|---|---|
| quote 匹配在「同文重复句」上误配 | 匹配按句子顺序取第一条未占用；同文重复句（如两个 "Yes."）→ 按出现顺序对齐；门禁造一组重复句反例 |
| AI payload 结构随意（字段别名、嵌套差异） | `parse_payload` 只认契约字段，缺字段按空处理并计入 unmatched；不做模糊猜测 |
| 用户粘贴带大量解释文字 | 容错解析只取**最外层 `{}`**（首个 `{` 到匹配的 `}`），其余丢弃并提示「已忽略 N 字说明文字」 |
| 后补解析误改原文 | `patch_ai_analysis` 只写 3 张解析表；门禁用前后快照断言 3 张结构表哈希不变 |
| 与 M5 快速导入状态互相污染 | 双 Tab 独立 state；切 Tab 清空 AI 中间态；AC1 断言快速导入不回归 |

**三问裁定**
1. **改动形态**：Rust 1 新模块（4 纯函数 + 6 命令）+ 前端 4 文件 + 1 门禁脚本 + 3 fixture + README，约 9 文件；零 schema、零新依赖（JSON 用 `serde_json`，已在依赖）。
2. **最便宜验证**：纯函数单测（`cargo test`，秒级）→ node 门禁三题型（秒级）→ CDP 走一遍四步（约 10 分钟，仅一次）。**不需要**全量打包。
3. **过度杀伤禁止项**：调外部 AI API / 带 key / 联网；改 schema；改快速导入路径与其 AC；自动修复 markup、自动猜句对齐、自动补答案；PDF/DOCX/OCR/文件选择器；`tauri build` 打包。
