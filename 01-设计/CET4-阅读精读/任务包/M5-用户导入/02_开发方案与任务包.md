## 一、验收标准

| 编号 | 判据 |
|---|---|
| **AC1** | **两阶段命令**：`parse_import_preview(text, title?)` 返回 `ImportPreview`（含 `title` / `paragraphs[{idx,text,sentences[{idx,start,end,text,tokens[]}]}]` / `stats{paragraphCount,sentenceCount,tokenCount,wordCount}`），**调用后库中零新增行**（**N-4**：`PRAGMA data_version` 同连接写入后不变、实测 1→1 **不可用**；改用 `db.total_changes()` **前后差值 = 0** + 九张核心表 `COUNT(*)` 快照比对）；`commit_import(preview, meta)` 单事务入库 |
| **AC2** | **清洗**：输入含 BOM / `\r\n` / `\r` / 零宽字符（`\u200b`）/ 连续空行 → 输出全部规范化（无 BOM、全 `\n`、无零宽、连续空行压成 1） |
| **AC3** | **分段**：空行分段，`paragraph.idx` 从 0 连续；纯空白段不产生 paragraph |
| **AC4** | **切句**：① `...end. Next...` → 2 句；② **缩写不断句**（**B-2 写死裁定**：**单一缩写表 + 命中即不断，不判断下一词大小写**——表含 `Mr.` `Mrs.` `Ms.` `Dr.` `Prof.` `St.` `Jr.` `Sr.` `vs.` `etc.` `e.g.` `i.e.` `U.S.` `U.K.` `a.m.` `p.m.` `No.` `Fig.`；故 `Mr. Smith said.` → **1 句** 且 `U.S. economy.` → **1 句**）；③ 小数 `3.14` 不断；④ 句末引号 `"Done."` 的 `"` 归属该句（`end` 含引号）；⑤ `?!` 同 `.`。**精度取舍**：`etc.` 后本应断句的场景会误判为不断，属可接受（用户在预览页能看到句数） |
| **AC5** | **分词与偏移**：每句的 token 覆盖该句除**空格**外全部字符（`sum(len(surface)) === len(text) - 空格数`）；`sentence.start/end` 相对 `paragraph.text`、`token.start/end` 相对 `sentence.text`，**逐条切片相等**；`isWord` / `normalized` 口径与内置内容包一致（`students'`→`students`、`day-to-day` 一个 token、纯数字 `isWord=false`） |
| **AC6** | **四层校验**（`commit_import` 内，任一失败即整体回滚）：L1 结构（段/句非空、idx 连续）/ L2 偏移（句子与 token 双级切片）/ L3 覆盖（token 铺满除空格）/ L4 业务（句数 ≥1、词数 ≥10、无控制字符）。**失败返回错误码**（`IMPORT_L1_STRUCTURE` / `IMPORT_L2_OFFSET` / `IMPORT_L3_COVERAGE` / `IMPORT_L4_BUSINESS` / **`IMPORT_TOO_LARGE`**（正文 > 20,000 字符）/ **`IMPORT_DUPLICATE_SOURCE`**）**且库中零写入** |
| **AC7** | **入库（B-3 重写）**：`article.visibility='user'`、`source_key='user-<uuid>'`（uuid 由 commit 时生成并返回）、`exam_type`/`exam_year` 取预览页所选（默认 `other` / `null`）；段落/句子/token 按序入库；**`article.sentence_count` 必须写真实句数**（B-3'：002 加的 `NOT NULL DEFAULT 0`，不写则文章库卡片显示「0 句」，`Library.tsx:377` 读它）；同时写 `paragraph_count`/`word_count`/`token_count`（若列存在）；**每次 commit 都是新文章（不覆盖）**；`source_key` 撞 UNIQUE 时返回 `IMPORT_DUPLICATE_SOURCE` 并整体回滚 |
| **AC8** | **文章库可见（N-1：现状已满足，零改动）**：文章库已有「内置 / 我导入的」Tab（`Library.tsx:201-220`）与按 visibility 筛选（`commands.rs:414-417`）→ 导入成功的文章出现在「我导入的」，内置 12 篇仍在内置组。**本 AC 只需验证，不需改代码** |
| **AC9** | **降级精读**（04 §6.4，**B-4 修复后可达**）：`has_analysis` 真实为 false → 点导入文章的句子 → 句子卡显示「**该篇无预置解析，可写笔记**」（不是空白、不是报错）；点词 → 词卡显示「暂无预置解析」且**「加入生词本」按钮在**（可收藏）；写笔记保存成功 |
| **AC10** | **预览页**：`#/import` 不再占位；有文本框 + 「解析预览」→ 显示 `stats`（段/句/词数）+ 段落列表（每段可勾选剔除）+ 标题输入 + 题型/年份选择 + 「确认导入」；`data-import-preview` / `data-import-stats` / `data-import-paragraph` / `data-import-commit` |
| **AC11** | **错误交互**：`parse` 或 `commit` 失败时，预览状态与用户编辑（标题、剔除）**保留不丢**；错误信息给错误码 + 可操作提示（如 L2 偏移 → 「文本含不可见字符，请重新粘贴」） |
| **AC12** | **不回归**：`verify:review`（135）、`verify:vocab`（180）、`verify:invoke`（例外 0）、`check-contrast`（≥38）、`verify:analysis`（274）、`verify:import`（现有内置导入）、`verify:pack`、`verify:sql`、`npm run build`、`cargo test --lib --bins` 全绿；`001_init.sql`/`01-设计/` 零改动；六个冻结 `data-*` 与 `data-vocab-state` 未改名 |

## 三、关键设计裁定（调度员，实现须遵守）

| # | 问题 | 裁定 |
|---|---|---|
| 1 | 切句在哪层做（Rust vs TS） | **Rust**（`import_user.rs`），与内置导入同侧；TS 只渲染预览 |
| 2 | 分词要不要复用 `render.ts` | **Rust 重写一份**（`render.ts` 是前端渲染用的，不能反向依赖）；**但口径必须一致**（AC5 的后三条）。token 化规则写成 `tokenize(text)` 纯函数 + 单测覆盖 `students'` / `day-to-day` / `1997` / `U.S.` |
| 3 | preview 传库还是传 ID | **preview 整个对象从前端回传**（`commit_import(preview, meta)`）——用户在预览页剔段改标题后，后端不该重算。**风险**：payload 大（500 词约 3 KB）；**缓解**：设上限（正文 ≤ 20,000 字符，超限报 `IMPORT_TOO_LARGE`） |
| 4 | L2 偏移校验为什么必要 | 前端只透传，若文本含不可见字符导致偏移错，入库后点词会错位。**这是入库前最后一道闸** |
| 5 | 幂等键 | `source_key='user-<uuid>'`，**uuid 由 commit 时生成并返回**；重复提交同一 preview 会产生新 uuid → **不算幂等**。真正的幂等：**同一篇导入后 `article.id` 复用于「重新导入」不做**（本包不做覆盖导入，登记债务） |
| 6 | 导入文章的复习 | **能进复习**（`mark_article_completed` 不区分 visibility）；本包不特殊处理 |
| 7 | 导入文章的名字 | `title` 默认取用户输入；空则取正文第一行前 40 字；再空则 `未命名导入 YYYY-MM-DD` |

## 五、风险

| 风险 | 缓解 |
|---|---|
| 切句规则永远不够（缩写表打不全） | 本包只保证 AC4 的五类；其余不完美属可接受（用户可在预览页看句数） |
| preview 回传 payload 大 | 上限 20,000 字符；超限报错 |
| ~~`list_articles` 不带 visibility~~ | **N-1 实证已带**（`commands.rs:408/498`）且已支持筛选（`:414-417`）、`Library.tsx:201-220` 已有 Tab → **D5 零改动**；**不要**扩展返回体（会踩 `verify-vocab.mjs:299`） |
| 导入文章无解析，用户觉得「没用」 | §6.4 已定降级文案；本包按设计做，产品判断归 M6 |

**三问裁定**
1. **改动形态**：**11 文件**（Rust：`import_user.rs` 新增 + `commands.rs` + `lib.rs` = 3；TS：`types.ts` + `api.ts` + `Import.tsx` + `SentenceCard.tsx` + `app.css` = 5；脚本：`verify-import-user.mjs` 新增 + `package.json` = 2；文档：`README.md` = 1）。**零 schema 改动**（`article.visibility`/`source_key` 已存在）。
2. **最便宜验证**：Rust 单测（秒级）+ `verify-import-user.mjs`（`node:sqlite` 临时库，秒级）+ CDP 一次完整「粘贴→预览→导入→在文章库看到」（3 分钟）。**不做全量打包**。
3. **过度杀伤禁止项**：`tauri build`；截图代证据；新依赖（**uuid 用 Rust 原生 `std` 或已有依赖，禁止新增 crate**——若必须，先用时间戳+随机数手写）；文件选择器；PDF/DOCX；自动生成解析；改 `001_init.sql`；改内置 12 篇；改六个冻结 `data-*`。
