# 01 · 需求分析（M5 用户导入）

> 上游：04 §6.2（两阶段导入）/ §6.4（解析降级）/ §五 M5 行｜设计基线 `DB-20261105-4`
> 用户 2026-11-06 指令：「修完 TP-修复5 的先不人工自查，**先进行 M5**，然后再一起自查」

## 一、要解决的问题

内置 12 篇是真题，但用户自己的材料（外刊、教材、TXT/MD）读不了。M5 让用户**粘贴或导入纯文本**，系统切段切句切词后入库，进精读页**降级阅读**（无预置解析，但能点词、能写笔记、能收藏生词）。

04 §五 M5 的验收口子：**粘 500 词 → 预览句数对 → 入库能在「我导入的」读到**。

## 二、做（7 项）

1. **两阶段命令**：`parse_import_preview(text, title?)` → `ImportPreview`（**不写库**）；`commit_import`（四层校验 + 单事务入库）
2. **文本清洗**：去 BOM、统一换行（`\r\n`/`\r` → `\n`）、去零宽字符、压连续空行
3. **分段 + 切句**：空行分段；句末 `.?!`（含紧跟的引号/括号）断句；**缩写排除表**（`Mr.` `Dr.` `U.S.` `e.g.` `i.e.` `etc.` 等不断）；小数与版本号不断
4. **分词**：与内置内容包同口径（`isWord` / `normalized` / UTF-16 偏移）
5. **预览页交互**：改标题、剔除某段、选考试类型与年份（默认「其他 / 未知」）
6. **入库后可见**：文章库出现「**我导入的**」分组；`visibility='user'`、`source_key='user-<uuid>'`
7. **降级精读**（04 §6.4）：无 `sentence_analysis` → 句子卡显示「该篇无预置解析，可写笔记」；词卡无预置解析 → 「暂无预置解析」但**仍可收藏**

## 三、不做

- 不做文件选择器 / 拖拽（**只做粘贴**；TXT/MD 文件读取归 M6+，因为要处理路径限域与 `basename` 化，04 §6.8 有专门要求）
- 不做 PDF / DOCX / OCR
- 不做自动翻译 / 自动生成解析（**导入文章就是无解析**，这是 §6.4 的降级设计）
- 不做导入内容的编辑（导入后只能删，不能改原文）
- 不做去广告/正文提取算法（用户自己在预览页剔段）
