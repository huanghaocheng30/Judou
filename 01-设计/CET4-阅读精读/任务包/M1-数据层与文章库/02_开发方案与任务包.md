## 三、具体改动点（逐条可执行）

- `src/styles/app.css` 的 `.tag` 规则：`color: var(--accent)` → `color: var(--ink-2)`（复算：浅色 6.18:1 / 深色 6.25:1）。
- `scripts/check-contrast.mjs` 加 `.tag` 的「文字 on 填充色」配对判据（当前 14 项 → 15 项）。
- **红→绿**：先加判据跑出 FAIL（贴 3.73 实测），再改 CSS 跑出 PASS（贴新值）。
- **消费接口**：`tokens.css` 变量（不改）；**产出接口**：无。

### D1 · `002` 迁移（对应 AC2）
```sql
ALTER TABLE token    ADD COLUMN is_word        INTEGER NOT NULL DEFAULT 1;
ALTER TABLE article  ADD COLUMN pack_version   TEXT;
ALTER TABLE article  ADD COLUMN sentence_count INTEGER NOT NULL DEFAULT 0;
```
- **不得改 `001_init.sql`**（一字节都不动）。
- `db.rs` 的迁移循环需支持「按 `schema_meta.version` 依次执行 002、003…」；执行后 `version=2`。
- `is_word` 落**内容包权威 `isWord`**（`true→1/false→0`），**不做 `normalized` 推导**（推导会把空格 token `"26"` 判成词，30 个空格全丢）。
- **消费接口**：`001` 建的表；**产出接口**：三列供 D3（写）与 D4/D6（读）。

### D2 · 内容包落位与 manifest（对应 AC1）
- 把 `01-设计/CET4-阅读精读/内容包/` 下 **12 篇 JSON + `manifest.json`** 拷入 `02-代码/content-pack/`（逐字节一致，用 SHA-256 自证）。
- `manifest.json` 结构（已由调度员生成，**不改字段名**）：
  - 顶层：`packVersion`（`2026.11.05-1`）、`contentVersion`、`generatedAt`、`schemaVersion`、`note`、`articles[]`、`totals{}`
  - `articles[i]`：`sourceKey` / `articleId` / `file` / `title` / `examType`（`cet4`）/ `examYear` / `examSet` / `sectionType`（`careful`/`long`/`cloze`）/ `sectionLabel`（中文）/ `passageLabel` / `wordCount` / `paragraphCount` / `sentenceCount` / `tokenCount` / `questionCount` / `blankCount` / `visibility`
  - `totals`：12 / 90 / 274 / 6699 / 274 / 213 / 30 / 90 / 1561
- `tauri.conf.json` 加 `"bundle": { "resources": { "content-pack/": "content-pack/" } }`（v2 资源映射形态按实际 CLI 版本对齐；若形态不同按官方写法并在 `concerns` 说明）。
- 运行期定位：优先 `resource_dir()/content-pack`，开发模式回落 `CARGO_MANIFEST_DIR/../content-pack`；两条都试，失败返回 `PackMissing`（不 panic）。
- **消费接口**：内容源文件（只读）；**产出接口**：包目录解析函数 + manifest 结构体（供 D3）。

### D3 · 幂等导入引擎（对应 AC3 / AC4）
- 顺序：读 `manifest.json` → 比 `schema_meta.pack_version`（**单一权威**，篇内 `packVersion` 忽略）→ 相等则返回 `{imported:0, skipped:12, elapsedMs}` 且**零写入** → 不等则**单事务** upsert。
- 9 张内容表写入映射（严格按 `05 §二` 建表落点表）：
  - `article`：`source_key` UNIQUE upsert；`title/source/exam_type/exam_year/exam_set/section_type/word_count/visibility='system'/pack_version/sentence_count`；`exam_type` 取 manifest 的 `cet4`
  - `paragraph`：`idx` 从 0
  - `sentence`：`start_offset/end_offset` **相对段落**（内容包已按此口径）；`text_hash` = `sha256(text)` 前 16 位十六进制
  - `token`：`start_offset/end_offset` **相对句子**；`is_word` = 内容包 `isWord`；`lemma`/`pos` 留空（ADR-009）
  - `question`：`options_json` = `[{key,text}]`；`explanation` 优先取内容包 `answer` 之外的解析（若为空则空串）
  - `blank`：`blank_no`/`answer_key`/`answer_word`/`reason`/`distractors`（`distractors` **归一为 JSON 字符串**；读取侧兼容字符串/数组两形态）
  - `sentence_analysis`：9 字段（`translation_literal`/`translation_natural`/`struct_markup`/`structure_summary`/`paragraph_role` + 4 个 `*_json`）
  - `token_analysis`：7 字段（`phonetic`/`pos`/`sense_in_context`/`collocations_json`/`examples_json`/`is_cet4_high_freq`/`more_json`），来自 `token.analysis`
  - `lexicon`：12 篇切片合并去重（`normalized` PK，1561 行）
- `ImportReport{imported, skipped, elapsedMs}`；启动时自动跑一次，结果写日志供取证。
- **失败回滚**：事务内任何错误回滚，旧版本数据仍可用；返回 `PackCorrupt{file}` 而非 panic。
- **绝不写**用户 8 表。
- **消费接口**：D1 三列 + D2 manifest；**产出接口**：内容表数据（供 D4/D6）。

### D4 · 命令层（对应 AC5 / AC6 的数据侧）
- `list_articles(filter)` → `ArticleSummary[]`（含五项字段，`sentence_count` 取冗余列避免 N+1；支持 `visibility`/`exam_type`/`exam_year`/`section_type`/`source`/`keyword`）
  - 搜索：`title LIKE '%'||?||'%' ESCAPE '\'`，对 `%`/`_` 转义
  - 排序：`exam_year DESC, exam_set, section_type, title`
- `get_article_content(articleId)` → `{article, paragraphs[{idx,text,sentences[{idx,start,end,text,tokens[{id,start,end,surface,normalized,is_word}],blankNos[]}]}], questions[{idx,stem,options,answer?}], hasAnalysis}`
  - **`blankNos` 由后端按 `blank` 表给出**（该篇 `blank_no` 列表），前端不猜
  - `hasAnalysis`＝该篇是否有 `sentence_analysis` 行（用户导入篇为 false，M5 用）
- `list_article_filter_options()` → `{examTypes[], years[], sectionTypes[], sources[]}`
- `import_content_pack()` → `ImportReport`（手动触发/自测用；正常由启动流程调用）
- 全部经 `api.ts` 封装；`.ts/.tsx` 除 `api.ts` 外零裸 `invoke(`。
- **消费接口**：D3 数据；**产出接口**：`api.ts` 的四个封装（供 D5/D6）。

### D5 · 文章库页（对应 AC5）
- 一级 Tab：**内置**（`visibility='system'`）/ **我导入的**（`user`）；空分组显示引导（「还没有导入材料 → 去导入」，跳 `#/import`）。
- 筛选器（原生 `select`/`button group`，不用自定义下拉）：考试类型 / 年份 / 题型 / 来源；条件 AND、同组多选 OR。
- 搜索框：标题模糊，输入防抖 250ms。
- 卡片五项字段：**篇名 / 年份 / 题型 / 词数 / 句数**（与 manifest 逐项一致）。
- **URL query 同步**：`#/library?vis=system&exam=cet4&year=2023&sec=careful&q=busy`；刷新/返回保持。
- 键盘：卡片可 Tab 聚焦、Enter 进入（`role="link"` + `tabIndex=0`）。
- **消费接口**：D4 的 `list_articles`/`list_article_filter_options`；**产出接口**：路由跳转到 `#/article/:id`（供 D6）。

### D6 · 精读只读渲染（对应 AC6 / AC7）
- **纯函数先行**：`src/lib/render.ts` 的 `renderTokens(text, tokens, blankNos): TokenNode[]`
  - 节点类型：`{kind:'text'|'word'|'blank', text, tokenId?, normalized?, start?, blankNo?}`
  - 空格判定**三条件**：`is_word === false`（落库为 `is_word=0`）**∧** `surface` 匹配 `/^\d+$/` **∧** `Number(surface) ∈ blankNos`
  - 顺序与偏移严格对齐；`Σ nodes.text === text`（逐字相等）
- 渲染：逐段 → 逐句 → `renderTokens` 输出映射到 JSX；词节点 `data-token-id`/`data-n`/`data-start`；空格节点 `data-blank-no`（**属性名不得改**）。
- 题目区：默认折叠，展开显示题干 + 选项（**选项不可点、答案不显示**——M2 才做交互）。
- 版式：纸感正文（`max-width: 66ch` 居中）、段落间距、句中词可 hover 高亮（不做点击态）。
- 返回：页头返回控件接路由历史（修 AC7 的原型缺陷）。
- **消费接口**：D4 的 `get_article_content`；**产出接口**：`renderTokens` 供 M2 复用（M2 只加交互，不改节点契约）。

### D7 · 路由与返回（对应 AC7）
- `#/article/:id` 参数解析（自写 hash 路由扩展，**仍不引入 react-router**）。
- 返回：优先 `history.back()`，无历史时回落 `#/library` 并**保留原 query**。
- **消费接口**：D5 的跳转；**产出接口**：可复用的 `useReturn()`（M2~M6 复用）。

### D8 · 门禁脚本（对应 AC3 / AC4 / AC6）
- `scripts/verify-import.mjs`：用 `node:sqlite` 只读查库 → 断言 9 张内容表行数为 `12/90/274/6699/274/213/1561/30/90`、`pack_version` 全等 manifest、篇内残留版本未入库、`MAX(id)`/`COUNT(*)` 供幂等复查。
- `scripts/verify-render.mjs`：从库取 274 句 + 6699 token → 跑 `renderTokens` → 断言逐字相等（0 例外）、空格 30/30、固有数字零误判、长文耗时 < 50ms。
- `scripts/check-contrast.mjs`：加 `.tag` 配对（D0）。
- **消费接口**：库与纯函数；**产出接口**：可复跑的门禁（供审查与后续包）。
