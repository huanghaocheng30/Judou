## 一、需求摘要与验收标准

**目标**：交付一个可启动的 Tauri v2 桌面应用：能把 12 篇内容包导入本地库，展示三套 12 篇的篇目列表（五项字段），点进任意一篇能看到**渲染正确的正文**（可点词、可点空的节点存在但交互留待 TP2/TP3），能从阅读页退回目录，并在内容包缺失/库损坏时给出可见处置而不是白屏。

**本包不做**：句卡（TP2）、词卡与词库查询（TP3）、题目与空格解析（TP4）、笔记/生词本/位置恢复（TP5）、目录卡片「已收藏生词数」（TP3 起）。

| 编号 | 验收标准（可测） |
|---|---|
| AC1 | 应用可启动，首屏显示总目录：三套分组、12 个篇目入口，每条显示 **篇名 / 年份 / 题型 / 词数 / 句数**；显示值与 `content-pack/manifest.json` 逐篇一致（句数 20/15/42/9/15/17/39/10/19/21/58/9，词数 350/345/1023/228/348/344/990/237/345/343/1030/237，年份统一 2023/12） |

## 三、具体改动点（逐条可执行）

### D1 · 工程骨架与资源映射（对应 AC1 / AC7 / AC9①）
- Tauri v2 + Vite + TypeScript，原生 DOM。**SQLite 驱动定死 `rusqlite`**（本包只发 Windows，`tauri-plugin-sql` 的跨平台理由不成立；如遇阻塞按 BLOCKED 上报，不得自行换库）。
- `tauri.conf.json` 配 `bundle.resources: { "../content-pack/": "content-pack/" }`（内容包必须随安装包分发，否则安装形态下 AC2 读不到）。
- **消费接口**：无。**产出接口**：
  - ① `lib.rs` 的 `invoke_handler` 注册骨架（供 D3/D4/D5 挂命令）；
  - ② 前端挂载点 `#app` + `router.ts` 路由表（供 D4/D5 注册页面）；
  - ③ 打包资源映射（供 D3/D5 运行时定位 `content-pack/` 与 DB 路径）。

### D2 · 内容包落位与 manifest（对应 AC2 输入）
- 12 个 `cet4-2023-12-*.json` 原样拷入 `content-pack/`（**逐字节一致**，不得改写内容）。
- `scripts/gen-manifest.mjs` 生成 `manifest.json`：
  ```json
  { "packVersion": "2023-12-v1",
    "articles": [{ "sourceKey": "...", "file": "cet4-2023-12-set1-passageA.json",
                   "contentHash": "<sha256 of file bytes>", "sentenceCount": 20 }] }
  ```
- **口径（已裁决，照做）**：
  - `file` 相对 **`content-pack/` 目录**；
  - `contentHash` = 对**整篇 JSON 文件字节**取 sha256，**仅作诊断/变更可见性**，不参与版本判定；
  - `manifest.packVersion` 是**唯一版本权威**；篇内残留 `packVersion: "2023-12-set1-v0.9"` **不入库、不参与比较**；`article.packVersion` 一律写 manifest 值。
- **消费接口**：无。**产出接口**：`manifest.json`（供 D3）。

### D3 · 导入命令（Rust 侧）（对应 AC2 / AC3 / AC6 / AC9①）
命令 `import_content(packDir) -> Result<ImportReport, StartupError>`：
1. 读 `manifest.json`；**文件缺失或 JSON 解析失败 → 返回 `Err(StartupError::PackMissing{file})` / `PackCorrupt{file}`**（不得 panic，不得静默继续）；
2. 读 `app_meta.packVersion`：**相等 → 直接返回 `{imported:0, updated:0, skipped:12, elapsedMs}`，不做任何写入**（05 §二 规则 1）；
3. 不相等 → **单事务**内逐篇 upsert，结束写 `app_meta.packVersion = manifest.packVersion`；失败回滚；
4. `ImportReport` 必须含 `elapsedMs`（`std::time::Instant`，覆盖整段导入）。

**`packDir` 运行期来源**：Rust 侧用 Tauri `resource_dir()` / `PathResolver::resolve_resource("content-pack")` 解析（**不拼绝对路径**）；开发态回退到 `../content-pack`。

### D4 · 总目录页（对应 AC1 / AC8 去程）
- 三套分组卡片；五项字段：篇名 / 年份 / 题型 / 词数 / 句数。数据来自 **`list_articles()`** 读本地库（`sentenceCount` 用落库聚合列，不在前端现算）。
- 卡片为 `<a href="#/article/<sourceKey>">`，可 Tab 聚焦、`:focus-visible` 有可见轮廓；题型用文字标签，不靠颜色单独表意。
- **消费接口**：D3 的 `article` 表；D1 的路由表；**D6 的「数据库已重建」提示状态**（重建后需在目录顶部显示提示横幅）。**产出接口**：
  - ① 命令 **`list_articles() -> ArticleSummary[]`**（`sourceKey/title/examYear/examMonth/section/wordCount/sentenceCount`）；
  - ② 路由 `#/article/<sourceKey>` 的生成侧（供 D5 消费）。

### D5 · 阅读页骨架与正文渲染（对应 AC4 / AC5 / AC8 回程）
- 路由 `#/article/<sourceKey>` → 调 **`get_article_content(sourceKey)`**（本改动点产出）取 `{article, paragraphs, sentences, tokens, blankNos}`；按 `paragraphs[].idx` 顺序渲染。
  - `blankNos` 来源：`SELECT no FROM blank WHERE articleKey = ?`（**不依赖前端解析 JSON**）。
- **渲染必须走纯函数** `renderTokens(text, tokens, blankNos)`（`src/render/tokens.ts`）：输入一句的 `text` 与 `tokens`，输出节点数组 `[{type:'text'|'word'|'blank', text, n?, start?, blankNo?}]`，由 DOM 层转节点。**纯函数不得触碰 DOM/窗口对象**，否则 AC5 无法 node 断言。
- **空格判定口径（定死，防误判正文数字）**：token 判为空格 ⟺ `token.isWord === false` **且** `surface` 匹配 `/^\d+$/` **且** `Number(surface) ∈ blankNos`。正文固有数字（`10/150/1997/2008/46/75/88,000/129` 等）不满足第三条，**不得**判为空格。
- 单词节点输出 `data-n`（normalized）与 `data-start`；空格节点输出 `data-blank-no` 与 `data-start`；句末输出「析」占位 `<button>`（不接交互，可 Tab 聚焦、有 `aria-label`）。
- **返回导航**：页头 `<a class="back" href="#/" aria-label="返回目录">‹</a>`；点击走路由历史返回（`history.state.fromCatalog` 为真时 `history.back()`，否则跳 `#/`），确保「点了必有反应」——原型缺陷的正式修复点。
- **消费接口**：D3 的 `paragraph`/`sentence`/`token`/`blank` 表；D4 的路由生成侧；D1 的路由表与挂载点。**产出接口**：
  - ① 命令 **`get_article_content(sourceKey)`**；
  - ② 节点属性契约 `data-n` / `data-start` / `data-blank-no`（供 TP2/TP3/TP4 接管，**不得改名**）。

### D6 · 启动异常处置（对应 AC9）
- **内容包异常**：`import_content` 返回 `Err(StartupError::PackMissing|PackCorrupt)` → 渲染 `pages/error.ts` 错误页，文案含**缺失/损坏的文件名**与「请重新安装或检查内容包」；**不进入空壳目录**（不含「12 篇」占位列表）。错误页文案由**纯函数** `renderErrorState(err) -> {title, detail, fileName}` 产出（不依赖 DOM/窗口，供 AC9 用 node 断言）。
- **数据库损坏**：`db.rs` 打开前做可读性探测（`PRAGMA schema_version` 失败）→ 关连接 → 把文件重命名为 `app.db.bak-YYYYMMDD-HHmm`（同目录）→ 建新库 → 重新导入 → 首页顶部提示「数据库已重建，原库已备份为 …」。
- **消费接口**：D3 的 `StartupError`；D1 的 DB 路径。**产出接口**：错误页与重建提示（供 AC9 取证）。

## 四、自测要求（每条 AC 至少一项机器可核证据；禁以截图/手工点选冒充）

> 纪律：每条结论附**真实命令 + 输出片段**；证据文件非空壳（字节 > 0 且含预期锚点）；统计数字必须与逐项证据算术一致。
> **人工级验证（视觉观感、可读性、真机手感）归用户实测**，开发员不以此冒充机器证据。

| AC9 | ① `mv content-pack/manifest.json manifest.json.bak` → 启动 → 断言错误页渲染纯函数输出含文件名（node 可测）+ 应用日志无 panic；② 用 `fs.writeFileSync` 把库文件前 1024 字节写成随机字节 → 启动 → 断言同目录出现 `app.db.bak-*` 且新库 12 篇 | ① 错误页文本含缺失文件名、无「12 篇」占位列表；② `app.db.bak-*` 存在 + 12 篇恢复 |

**AC5 三段样本断言（开发员照抄，不得放宽）**
1. **普通句**（`set1Long` 任一句）：每个 `isWord=true` 的 token → `{type:'word', n: normalized, start}`；所有节点 `text` 拼接必须等于原句 `text`。
2. **同句含空格与数字**（`set1Cloze` paragraph idx=1、sentence idx=2，原句含空号 `27`、`28` 与正文数字 `75`、`150`）：
   - `surface="27"` / `"28"`（∈ blankNos）→ 必须产出 `{type:'blank', blankNo:27|28}`；
   - `surface="75"` / `"150"`（∉ blankNos 的正文数字）→ 必须产出 `{type:'text'}`，**不得**为 `blank`；
   - 整句节点拼接必须复原原句。
3. **标点与空白覆盖**：相邻 token 之间未被覆盖的字符（空格、标点）必须原样产出 `{type:'text'}`。
