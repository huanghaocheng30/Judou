## 一、需求摘要与验收标准

**目标**：交付一个可启动的 Tauri v2 桌面应用：能把 12 篇内容包导入本地库，展示三套 12 篇的篇目列表（五项字段），点进任意一篇能看到**渲染正确的正文**（可点词、可点空的节点存在但交互留待 TP2/TP3），并能从阅读页退回目录。

**本包不做**：句卡（TP2）、词卡与词库查询（TP3）、题目与空格解析（TP4）、笔记/生词本/位置恢复（TP5）、目录卡片「已收藏生词数」（TP3 起）。

| 编号 | 验收标准（可测） |
|---|---|
| AC1 | 应用可启动，首屏显示总目录：三套分组、12 个篇目入口，每条显示 **篇名 / 年份 / 题型 / 词数 / 句数**；显示值与 `content-pack/manifest.json` 逐篇一致（句数 20/15/42/9/15/17/39/10/19/21/58/9，词数 350/345/1023/228/348/344/990/237/345/343/1030/237，年份统一 2023/12） |

## 三、具体改动点（逐条可执行）

### D1 · 工程骨架与资源映射（对应 AC1 / AC7）
- Tauri v2 + Vite + TypeScript，原生 DOM。**SQLite 驱动定死 `rusqlite`**（本包只发 Windows，`tauri-plugin-sql` 的跨平台理由不成立；如遇阻塞必须先按 BLOCKED 上报，不得自行换库）。
- `tauri.conf.json` 配 `bundle.resources: { "../content-pack/": "content-pack/" }`（**内容包必须随安装包分发**，否则安装形态下 AC2 读不到）。
- **消费接口**：无。**产出接口**：
  - ① `src-tauri/src/lib.rs` 的 `invoke_handler` 注册骨架（供 D3/D4/D5 挂命令）；
  - ② 前端挂载点 `#app` + `router.ts` 路由表（供 D4/D5 注册页面）；
  - ③ 打包资源映射（供 D3 运行时定位 `content-pack/`）。

### D2 · 内容包落位与 manifest（对应 AC2 输入）
- 12 个 `cet4-2023-12-*.json` 原样拷入 `content-pack/`（**逐字节一致**，不得改写内容）。
- `scripts/gen-manifest.mjs` 生成 `manifest.json`：
  ```json
  { "packVersion": "2023-12-v1",
    "articles": [{ "sourceKey": "...", "file": "cet4-2023-12-set1-passageA.json",
                   "contentHash": "<sha256 of file bytes>", "sentenceCount": 20 }] }
  ```
- **口径（本轮裁决，开发员照做）**：
  - `file` 相对 **`content-pack/` 目录**；
  - `contentHash` = 对**整篇 JSON 文件字节**取 sha256，**仅作诊断/变更可见性**，不参与版本判定（版本判定只看 `packVersion`）；
  - `manifest.packVersion` 是**唯一版本权威**。篇内残留的 `packVersion: "2023-12-set1-v0.9"` **不入库、不参与比较**；`article.packVersion` 一律写 manifest 值。
- **消费接口**：无。**产出接口**：`manifest.json`（供 D3）。

### D3 · 导入命令（Rust 侧）（对应 AC2 / AC3 / AC6）
命令 `import_content(packDir) -> ImportReport`：
1. 读 `manifest.json`；
2. 读 `app_meta.packVersion`：**相等 → 直接返回 `{imported:0, updated:0, skipped:12, elapsedMs}`，不做任何写入**（05 §二 规则 1）；
3. 不相等 → **单事务**内逐篇 upsert，结束写 `app_meta.packVersion = manifest.packVersion`；失败回滚。
4. `ImportReport` 必须含 `elapsedMs`（`std::time::Instant` 计时，覆盖整段导入）。

### D4 · 总目录页（对应 AC1 / AC8 去程）
- 三套分组卡片；五项字段：篇名 / 年份 / 题型 / 词数 / 句数。数据来自 **`list_articles()`** 命令读本地库（`sentenceCount` 用落库聚合列，不在前端现算）。
- 卡片为 `<a href="#/article/<sourceKey>">`，可 Tab 聚焦、`:focus-visible` 有可见轮廓；题型用文字标签，不靠颜色单独表意。
- **消费接口**：D3 的 `article` 表；D1 的路由表。**产出接口**：
  - ① 命令 **`list_articles() -> ArticleSummary[]`**（`sourceKey/title/examYear/examMonth/section/wordCount/sentenceCount`）；
  - ② 路由 `#/article/<sourceKey>` 的生成侧（供 D5 消费）。

### D5 · 阅读页骨架与正文渲染（对应 AC4 / AC5 / AC8 回程）
- 路由 `#/article/<sourceKey>` → 调 **`get_article_content(sourceKey)`** 取 `{article, paragraphs, sentences, tokens}`；按 `paragraphs[].idx` 顺序渲染。
- **渲染必须走纯函数** `renderTokens(text, tokens, blankNos)`（`src/render/tokens.ts`），输入一句的 `text` 与 `tokens`，输出节点数组 `[{type:'text'|'word'|'blank', text, n?, start?, blankNo?}]`，再由 DOM 层转成节点。**纯函数不得触碰 DOM/窗口对象**，否则 AC5 无法用 node 断言。
- **空格判定口径（本轮定死，防误判正文数字）**：一个 token 判为空格 ⟺
  `token.isWord === false` **且** `token.surface` 匹配 `/^\d+$/` **且** `Number(token.surface) ∈ blankNos`（本篇顶层 `blankNos` 数组）。
  正文固有数字（`10/150/1997/2008/46/75/88,000/129` 等）不满足第三条，因此**不得**被判为空格。
- 单词节点输出 `data-n`（normalized）与 `data-start`（start）；空格节点输出 `data-blank-no`（空格号）与 `data-start`；句末输出「析」占位 `<button>`（不接交互，但可 Tab 聚焦、有 `aria-label`）。
- **返回导航**：页头 `<a class="back" href="#/" aria-label="返回目录">‹</a>`；点击走**路由历史返回**（`history.back()`，仅当 `history.state.fromCatalog` 为真时用 back，否则直接跳 `#/`），确保「点了必有反应」——这是原型缺陷的正式修复点。
- **消费接口**：D3 的 `sentence`/`token`/`paragraph` 表；D4 的 `get_article_content` 归属见下；D1 的路由表与挂载点。
- **产出接口**：
  - ① 命令 **`get_article_content(sourceKey)`**（本改动点声明产出）；
  - ② 节点属性契约 `data-n` / `data-start` / `data-blank-no`（供 TP2/TP3/TP4 接管交互，**不得改名**）。

## 四、自测要求（每条 AC 至少一项机器可核证据；禁以截图/手工点选冒充）

> 通用纪律：每条结论附**真实命令 + 输出片段**；证据文件非空壳（字节 > 0 且含预期锚点）；统计数字必须与逐项证据算术一致。
> **人工级验证（视觉观感、可读性、真机手感）归用户实测**，开发员不以此冒充机器证据。

| AC | 自测手段（最便宜路径） | 通过判据 |
|---|---|---|
| AC1 | `node scripts/verify-render.mjs --catalog`：读 `manifest.json` 与库导出（或 `list_articles()` 的 JSON dump），逐篇打印 12 行「篇名/年份/题型/词数/句数」 | 12 行全非空；词数、句数与 manifest 及 §一 列表逐项相等；**12/12 通过** |
| AC2 | 删库 → `pnpm tauri dev`（或直接调 `import_content`）→ 贴 `ImportReport` JSON | `imported=12, updated=0, skipped=0, packVersion="2023-12-v1"`；`SELECT COUNT(*)` 四表 = 12 / 90 / 274 / 6699；`lexicon` = 1561；`question` = 90；`blank` = 30 |
| AC3 | 再启动一次 → 贴第二次 `ImportReport` | `imported=0, updated=0, skipped=12`；`elapsedMs < 2000`（首次与二次两次值都贴）；`article` 的 `rowid` 清单前后一致 |
| AC4 | `node scripts/verify-render.mjs --tokens`：遍历 12 篇，校验 `text.slice(start,end) === surface` | `6699/6699 一致，mismatch=0`；另贴 set3Long 第 6 段 3 句的正文与内容包原文比对 |
| AC5 | `node scripts/verify-render.mjs --nodes`：直接 import 纯函数，断言三段样本 | 见下方样本断言，全部 pass |
| AC6 | 记下库文件路径 → 删除 → 重启 → 再查 | 12 / 274 / `packVersion` 全部恢复；贴路径与查询输出 |
| AC7 | `pnpm tauri build`（**只跑一次**，不在修订验证里重复） | 命令 exit 0；贴 `bundle/msi/*.msi` 与 `bundle/nsis/*.exe` 的 `Get-Item` 体积，取较大者 < 30 MB |
| AC8 | 纯函数/DOM 层面：断言 `router` 的 `#/article/x` → `#/` 回退函数被调用；人工点测归用户 | 回退函数单测 pass + 路由表含两条记录 |

**AC5 三段样本断言（开发员照抄，不得放宽）**
1. 普通句（无空格）：每个 `isWord=true` 的 token 产出 `{type:'word', n: normalized, start}`；`text` 拼回必须等于原句。
2. 含空格句（cloze 篇）。**判据点**：`surface="26"` 且 `26 ∈ blankNos` → 产出 `{type:'blank', blankNo:26}`；而 `surface="150"`（正文固有数字、不在 `blankNos`）→ 必须产出 `{type:'text'}`，**不得**为 `blank`。
3. 相邻 token 间若有未覆盖字符（如空格、标点），必须原样产出 `{type:'text'}`，保证拼接回原句。

## 五、风险点与影响范围预估

| 风险 | 影响 | 缓解 |
|---|---|---|
| Tauri v2 首次构建拉依赖慢 | 构建 10+ 分钟 | 预算已计入。**编译环境（本轮实测，附精确路径）**：Rust 1.99.1（`x86_64-pc-windows-msvc`）；MSVC 14.44.35207 已装，`vcvars64.bat` 在 `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat`（注意是 `Program Files (x86)`，不是默认手册路径）；`cl.exe` **不在全局 PATH**，需先 `call` 该 vcvars64。依据：06 §二 决策#7 |
| 构建期需联网 | 无网则装依赖失败 | 构建期允许联网（npm registry=`npmmirror`、`index.crates.io` 可达，本轮实测）；**运行期不联网**，两件事不混淆 |
| 12 篇 JSON 约 3.36 MB 一次性入库 | 导入慢 | 单事务 + prepared statement；AC3 用 `elapsedMs` 实测，不用「应该很快」 |
| 中文路径 | 构建/读取失败 | `content-pack/` 用 ASCII 名；运行期经 Tauri 资源 API 定位，不拼绝对路径 |
| `blanks.distractors` 两种形态（字符串 / 数组） | 建表或渲染报错 | 归一为 JSON 字符串存储；读取侧兼容两者（06 §五#2 同类） |
| 篇内 `packVersion` 残留值 | 版本判断失真 | §三 D2 已定死：manifest 为唯一权威，篇内值不入库 |

**内容债（不改内容包，登记在此）**：12 篇 JSON 内 `packVersion="2023-12-set1-v0.9"` 为生产批次残留；set2/set3 的 8 篇占位标题已于 2026-11-05 补齐为真实篇名（见决策记录），**因此 AC1 的标题期望值以当前内容包为准，不是占位文字**。
