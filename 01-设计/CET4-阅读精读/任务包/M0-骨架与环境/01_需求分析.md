# 01 · 需求分析（M0-骨架与环境）

> 上游：`04_产品设计方案-v2.0.md` §五（M0 目标）、`05_分模块设计-v2.0.md` §一（模块总览）/§十七（跨模块约束）、`06_设计定稿记录-v2.0.md` §三（9 条开发规则）、`docs/D1-AGENTS项目级开发约束.md`、`docs/D2-开发环境与项目结构.md`
> 定位：方案 v2.0 的**第一个包**。M1~M7 全部建立在本包产出的工程骨架、数据库 schema 与主题系统之上。
> 与 TP1 的关系：TP1（v1.1 方案下的骨架实现，原生 DOM + 10 表）已验收通过并归档；**本包是按 v2.0 重写的起点，TP1 代码不继承**（仅 `renderTokens` 纯函数逻辑与 73 条断言可作为参考）。

## 一、为什么先做这一包

v2.0 把规模从「2 页阅读器」扩到「8 页工作台 + 18 张业务表（连 `schema_meta` 共 19 张）+ 复习 + 用户导入」。这些东西没有一个是能「后补」的：

- **18 张业务表（连 `schema_meta` 共 19 张物理表）**：笔记、生词、标签、复习、记录都挂在 `sentence_id`/`token_id` 外键上；表结构晚改一次，就要迁移用户数据一次。
- **导航壳与主题**：8 页共用一套壳与 CSS 变量；壳不定，后面每页都要返工。
- **图标与 CI**：发布链路（M7）依赖图标全套与 Actions 骨架，早做一次省后面的折腾。

所以本包刻意压到「能启动 + 库建好 + 命令通 + 主题能切 + 图标上包 + CI 空跑」，**一行内容逻辑都不写**。

## 二、用户可感知的交付

打开应用 → 窗口标题「句读」→ 左侧边栏（今日/文章库/复习/生词本/导入/记录/设置）→ 主区显示骨架占位「内容导入将在 M1 接入」→ 设置页可切 浅色/深色/跟随系统，重启保持 → 设置页底部**关于区**显示版本与图标（04 §八 把「关于」放在设置页内，不单列一页）。

此时**没有文章、没有解析、没有复习**——这是预期，M1 起逐个接入。

## 三、范围边界

**做**：
- Tauri v2 + **React** + Vite + TypeScript 工程骨架（含 `.gitignore`、tsconfig、vite 配置）
- **19 张物理表（18 业务 + `schema_meta`）的 `001_init.sql`** 与迁移框架（`schema_meta` 记版本）
- `ping` 命令 + `src/lib/api.ts` 唯一后端入口（禁止裸 `invoke`）
- 主题系统（浅/深/跟随，CSS 变量，`app_setting.theme` 持久）
- 导航壳（侧边栏 7 项 + 路由占位页）+ 设置页壳（**含关于区**：版本/License/免责占位）
- 应用图标全套（`tauri icon` 从 1024 源图生成，`tauri.conf.json` 引用，无默认图标残留）
- GitHub Actions 骨架（三平台 `cargo check` + `npm run build`；Android job 占位）

**不做**（明示延后）：
- 内容导入（12 篇入库）与 manifest → M1
- 文章库列表、筛选、精读页 → M1
- 句子解析卡、词卡、题目、空格、笔记 → M2
- 生词本 / 复习 / 用户导入 / 记录统计 / 导出 → M3~M6
- Android 实际打包（需 SDK/NDK/签名）→ M7
- 动效 → M2 起随组件

## 四、关键约束

1. **前端 React + Vite + TS**（docs ADR-005）；不引入 UI 框架（Ant/MUI 等），样式走 CSS 变量 + 自有组件（与原型 v2 的纸感方向一致）。
2. **19 张物理表 = 18 张业务表 + 1 张元表**：按 `04 §7.1`（表清单，其标题「18 表」为业务表口径、表格共 19 行）/`§7.2`（三处修订）/`§7.3`（三处新增列）落库，列定义见 `docs/C2 §4.1~§4.15`；分类为**内容 9 张 / 用户 8 张 / 配置 1 张（`app_setting`）/ 元 1 张（`schema_meta`）**（口径同 `05 §十七.1`），物理分离。本包只建表，**不写入任何内容或用户数据**（除默认设置）。
3. **`schema_meta` 是唯一版本表**（合并 v1 的 `app_meta`）；`001_init.sql` 发布后不再修改，后续结构变更走 `002_*.sql`。
4. **前端只经 `api.ts`**（docs D1 §7.4），组件里出现裸 `invoke` 即返工。
5. **运行期不联网**：本包除 `check_update`（M7 才有）外不得有任何网络请求。
6. **图标必须是「句读」图标**：`icons/` 全套由 `tauri icon` 从 1024 源图生成，`tauri.conf.json` 的 `bundle.icon` 指向它们，**无 Tauri 默认图标残留**；安装态任务栏/开始菜单观感归 M7 实测（M0 不做全量打包）。
7. 改动只限 `02-代码/`。

## 五、验收摘要

7 条验收标准见 `02_开发方案与任务包.md` 第一节；AC1（能启动）、AC2（**19 张物理表**建全）、AC5（图标上包）是本包能否叫「完成」的硬门槛。
