## 三、具体改动点（逐条可执行）

### D1 · 工程骨架（对应 AC1 / AC7）
- React 18 + Vite 6 + TypeScript；`@vitejs/plugin-react`；dev server 固定 **1420**（Tauri 约定）。
- Tauri v2：`tauri.conf.json` 设 `productName:"句读"`、`identifier:"com.judou.app"`、窗口 1200×800、`resizable:true`。
- 路由：hash 路由（与原型一致：`#/today`、`#/library`、`#/article`、`#/review`、`#/vocab`、`#/import`、`#/records`、`#/settings`），**不引入 react-router**（`ponytail:` 注释注明：8 页 hash 路由够用，需要嵌套/守卫再引入）。
- **消费接口**：无。**产出接口**：
  - ① `invoke_handler` 注册骨架（供 D3 挂命令）；
  - ② `src/shell/routes.tsx` 路由表 + 挂载点（供 M1~M6 注册真实页面）；
  - ③ `styles/tokens.css` 的 CSS 变量命名（供全部页面使用）。

### D2 · 数据库 schema 与迁移（对应 AC2）
- **19 张表**（05 §七 的 18 张 + `schema_meta`，注意清单里 `schema_meta` 与 `app_setting` 都在）：

| 分类 | 表 | 关键列 |
|---|---|---|
| 元 | `schema_meta` | `key` PK, `value`（含 `version`） |
| 内容 | `article` | `id` PK, `source_key` UNIQUE, `title`, `source`, `exam_type` CHECK(`cet4`,`cet6`,`other`), `exam_year`, `exam_set`, `section_type`, `difficulty`, `word_count`, `visibility` CHECK(`system`,`user`), `status`, `created_at`, `updated_at` |
| 内容 | `paragraph` | `id`, `article_id` FK CASCADE, `idx`, `text` |
| 内容 | `sentence` | `id`, `article_id`, `paragraph_id`, `idx`, `text`, `text_hash`, `start_offset`, `end_offset` |
| 内容 | `token` | `id`, `sentence_id`, `idx`, `surface`, `normalized`, `lemma`, `start_offset`, `end_offset`, `pos` |
| 内容 | `question` | `id`, `article_id`, `idx`, `stem`, `options_json`, `answer`, `explanation` |
| 内容 | `blank` | `id`, `article_id`, `blank_no` UNIQUE(article,no), `answer_key`, `answer_word`, `reason`, `distractors` |
| 内容 | `sentence_analysis` | `id`, `sentence_id` UNIQUE, 5 文本列 + 4 JSON 列（见 05 §七） |
| 内容 | `token_analysis` | `id`, `token_id` UNIQUE, 7 列（含 `is_cet_high_freq` INTEGER） |
| 内容 | `lexicon` | `id`, `normalized` UNIQUE, `word`, `phonetic`, `pos`, `sense`, `lemma`, `collocations_json`, `examples_json`, `is_cet_high_freq`, `more_json` |
| 用户 | `sentence_note` | `id`, `sentence_id` UNIQUE, `translation`, `grammar_note`, `phrase_note`, `updated_at` |
| 用户 | `word_note` | `id`, `token_id` UNIQUE, `context_meaning`, `collocation`, `example`, `updated_at` |
| 用户 | `vocab_entry` | `id`, `normalized` UNIQUE, `surface`, `phonetic`, `pos`, `context_meaning`, `source_sentence_id`, `source_article_id`, `mastery` CHECK(`new`,`fuzzy`,`known`), `review_count`, `last_reviewed_at`, `created_at`, `updated_at` |
| 用户 | `tag` | `id`, `name` UNIQUE, `color` |
| 用户 | `vocab_tag` | `vocab_id`, `tag_id`, PK(vocab_id,tag_id) |
| 用户 | `review_plan` | `article_id` PK, `next_review_at`, `interval_index`, `status` CHECK(`active`,`paused`,`done`) |
| 用户 | `review_log` | `id`, `article_id`, `reviewed_at`, `interval_index`, `result` |
| 用户 | `reading_record` | `article_id` PK, `last_position`, `duration_sec`, `completed`, `last_read_at` |
| 配置 | `app_setting` | `key` PK, `value` |

- 索引：`article(visibility, exam_type, exam_year, section_type)`、`sentence(paragraph_id, idx)`、`token(sentence_id, idx)`、`vocab_entry(normalized)`、`review_plan(status, next_review_at)`
- 迁移：`db.rs` 启动时读 `schema_meta.version` → 顺序执行 `migrations/00N_*.sql`（本包只有 001）；执行后写回 version。**已发布的 001 不得修改**。
- 默认数据：只写 `app_setting` 的 `theme='system'` 与 `guide_shown='0'`（幂等：`INSERT OR IGNORE`）。
- **消费接口**：无。**产出接口**：① 连接与迁移 API（供 M1 导入）；② `app_setting` 读写（供 M6 设置）。

### D3 · `ping` 命令与 api.ts（对应 AC3）
- Rust：`#[tauri::command] fn ping() -> PingResult { pong:true, appVersion: env!("CARGO_PKG_VERSION") }`，注册进 `invoke_handler`。
- 前端：`src/lib/api.ts` 导出 `ping()`；`App.tsx` 启动时调用一次并在控制台打印结果（用于取证）。
- **禁止裸 `invoke`**：除 `api.ts` 外任何 `.ts/.tsx` 出现 `invoke(` 即返工（脚本断言）。
- **消费接口**：D1 的 `invoke_handler`；**产出接口**：`api.ts` 的封装模式（后续所有命令照此）。

### D4 · 主题系统（对应 AC4）
- `styles/tokens.css` 定义浅/深两套变量（纸底/墨/靛蓝/玫红/陶土橘/线色，取值来自原型 v2）。
- `ThemeProvider`：读 `app_setting.theme` → 在 `<html data-theme>` 上应用；`system` 模式监听 `matchMedia`。
- 设置页：三段控件（浅/深/跟随）→ 调 `set_setting('theme', v)` → 立即生效。
- **消费接口**：D2 的 `app_setting`；**产出接口**：`useTheme()` hook + CSS 变量（供全部页面）。

### D5 · 应用图标流水线（对应 AC5）
- 源图：`01-设计/CET4-阅读精读/原型-v2/icon/句读-选定-1024.png`（**只读引用，拷入 `02-代码/` 后再生成**）。
- 执行 `npx tauri icon <源图> -o src-tauri/icons`，产出全套（32/128/128@2x/256/512、`icon.ico`、`icon.png`）。
- `tauri.conf.json` 的 `bundle.icon` 引用 `icons/32x32.png`、`icons/128x128.png`、`icons/icon.ico`。
- **验收注意**：`tauri icon` 会同时生成 Android/iOS 目录，本包保留（M7 用）；但 `bundle.icon` 只引用桌面那几项。
- **消费接口**：图标源图（只读）；**产出接口**：`icons/`（供 M7 打包）。

### D6 · CI 骨架（对应 AC6）
- **位置**：工作流必须放在**仓库根** `.github/workflows/ci.yml` 才生效；但仓库根不属于 `02-代码/`（本包目标代码区）。
  **处理（本轮裁定）**：文件写在 `02-代码/.github/workflows/ci.yml` 并在 `README.md` 注明「M7 收尾时移动到仓库根」；**本包不写仓库根**（越界）。AC6 的校验只验该文件存在 + YAML 可解析 + job 名齐全。
- 内容：`windows-latest`（主要）+ `ubuntu-latest`（可选）→ `npm ci` + `npm run build` + `cargo check`；Android job `if: false` 占位。
- **消费接口**：无；**产出接口**：CI 骨架（供 M7 启用）。
