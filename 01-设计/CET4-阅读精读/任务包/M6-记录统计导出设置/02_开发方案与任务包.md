## 三、关键契约

1. **连续天数**：取 `reading_record.last_read_at` 的日期集合（`YYYY-MM-DD` 去重降序）；今天有记录 → 从今天；今天无 → 从昨天起算；逐日递减，遇到缺口停。返回 0 表示无记录。
2. **HTML 自包含**：全部样式写 `<style>`，**不允许** `<link rel="stylesheet">`、`<script src=`、`http(s)://` 外链；字体用系统字体栈。
3. **恢复安全**：`restore_db` 先写 `*-pre-restore-YYYYMMDD-HHmm.db` 备份 → 校验源文件是合法 SQLite 且含 `article` 表 → 在**临时副本**上校验表计数 → 原子替换（`std::fs::rename`）→ 失败则保留原库并返回错误。
4. **主题持久**：`app_setting` 键 `theme`，值 `light|dark|system`；前端 `data-theme` 三态，`system` 用 `prefers-color-scheme`。
5. **幂等**：`get_settings` 首次调用时写入默认值（`theme=system`、`guide_shown=0`）。
