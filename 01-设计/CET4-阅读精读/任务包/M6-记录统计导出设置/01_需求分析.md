# 01 · 需求分析（M6-记录统计导出设置）

> 上游：04 v2.2 §五（M6 里程碑）/ §6.5-6.6 / §8 页面清单；05 v2.2 §十二（M11）§十三（M12）§十四（M13）§十五（M14）
> 依赖前置：M3 生词本 ✅、M4 复习 ✅（`reading_record`/`vocab_entry`/`app_setting` 表均已存在）
> **未决澄清项：无**

## 一、目标

把「读过的痕迹」变成用户看得见的东西，并提供数据出口与全局设置：
1. **记录与统计**：时间线 + 六项统计（篇数/已完成/总时长/笔记数/生词数/复习次数 + 连续天数）
2. **导出与备份**：生词本导出为自包含 HTML；整库备份与恢复（恢复前自动备份）
3. **设置与主题**：主题三档即时生效并持久；复习间隔只读展示；关于页
4. **首次引导**：三屏引导（可跳过）+ 四个空态都有「下一步做什么」

## 二、范围

**做**：7 个命令（`get_reading_records` / `get_stats` / `export_vocab_html` / `backup_db` / `restore_db` / `get_settings` / `set_settings`）+ 记录页 + 设置页 + 首次引导 + 四空态。

**不做**：不改 schema（`reading_record`/`app_setting` 已存在）；不做复习间隔可改（只读展示）；不做云同步/上传；不做 updater（归 M7）；不做 Android。
