## 二、验收标准（AC1~AC6）

| 编号 | 判据 |
|---|---|
| **AC1** | `index.html` 的 viewport 加 **`viewport-fit=cover`**（前提：否则 AC2/AC3 的 `env()` 全为 0） |
| **AC2** | **底部安全区**：`.sidebar`（<640）高度改 `calc(56px + env(safe-area-inset-bottom, 0px))`，`.shell` 的 `padding-bottom` 同步加上该 inset → 底部 Tab 不被系统手势条遮住 |
| **AC3** | **顶部安全区**：`.topbar` 的 `padding-top` 改 `calc(22px + env(safe-area-inset-top, 0px))`（窄屏可另设基础值 12px）→ 内容不被状态栏遮挡 |
| **AC4** | **「析」触摸热区 ≥44×44 CSS px**：`.sentence-mark` 扩大可点击区域（padding + 负 margin 抵消布局影响，或用 `::after` 绝对定位扩展热区到 44×44）；**视觉尺寸可保持小巧**（用户要的是好点，不是好大）；悬停/聚焦高亮保留 |
| **AC5** | **「返回文章库」窄屏不挤压标题**：<640px 时该按钮独占一行（或改图标按钮 `‹` + `aria-label`），标题获得完整宽度 |
| **AC6** | **单词标记更明显**：① 有笔记的单词：底部圆点改为**更醒目的形状**（加粗下划线或角标），与句子「析」变红形成一致的「已标记」语义；② **加入生词本后有明显变化**（如词下出现实心标记 / 卡片内显示「已收录」） |
| **AC7** | 回归：`npm run build` / 15 项 manifest 门禁 / `cargo test`（73 passed）全 EXIT=0；**桌面 1920 布局与改前逐项 SAME**（M9 的做法） |
| **AC8** | **真机复验**（需用户重新插 USB）：`adb install -r` → 启动 → 截图；重点看顶部/底部是否让出安全区、「析」能否点中。**未真机验证不得置已完成** |

## 六、风险

| 风险 | 应对 |
|---|---|
| `env(safe-area-inset-*)` 在 Tauri Android WebView 是否支持 | Tauri v2 用系统 WebView（Chromium 内核），支持 `env()`；但**必须**有 `viewport-fit=cover`。若发现不支持 → 退回用固定值（`padding-top: 32px`）并记录 |
| 「析」热区扩大后与相邻单词重叠 | 用 `::after` 扩展热区（不占布局），并确保 `z-index` 不压住单词点击 |
| 桌面布局被改坏 | AC7 要求 1920 逐项 SAME |
