## 二、改动点

### F0 · 先实测三页基线（不许跳过）
CDP **真实窗口 1920** 下分别进 `#/library`、`#/vocab`、`#/article/<某篇>`，记录：`.content` 的 `clientWidth` / `marginLeft` / `marginRight` / `getBoundingClientRect()`、文章库卡片容器宽与首列卡片宽、生词本列表宽、精读页 `.reader-body` 宽与右栏宽。数字写进自测后再改。

### F1 · 按页面区分居中（唯一改动）
`app.css`：

```css
.content {
  flex: 1;
  padding: 26px 32px 40px;
  max-width: 1100px;
  /* 列表页（文章库/生词本/复习/记录/导入/设置）左对齐铺开 —— 全局居中会把卡片区压成窄条（TP-修复2 回归） */
}

/* 精读页保留居中：用户 2026-11-06 复测认可该形态（正文 66ch + 右栏 360） */
.content:has(.reader) {
  margin-inline: auto;
}

@media (min-width: 1440px) {
  .content { max-width: 1240px; }
}
```

- **保留** `@media (min-width:1440px){ max-width:1240 }`（列表页在超宽屏能排更多列，精读页也受益）
- **保留** `.reader-body` 的 `max-width:66ch`、`.reader-split` 的 `minmax(0, 1fr) 360px`（BL-2 已确认的正确形态）
- **若 `:has()` 在 WebView2 v156 不支持**（F0 时先用 CDP 试一条 `document.querySelector('.content:has(.reader)')` 确认）：退化方案是给 `Reader.tsx` 的 `<section>` 外套一层或给 `.content` 加 `data-page="reader"` 属性 + `.content[data-page="reader"] { margin-inline:auto }`。**二选一，不要两个都上**。

## 四、风险

| 风险 | 缓解 |
|---|---|
| `:has()` 不支持 → 精读页也失去居中 | F0 先验证；退化方案用 `data-page` 属性（见 F1） |
