## 一、需求摘要与验收标准

**目标**：把「精读时碰到的好词」变成**可积累的资产**——收藏（同词一条）、三种轴看、能编辑打标签改掌握状态、点回原句定位、文章删了生词还在。**不做导出（归 M6）、不做复习（M4）。**

| 编号 | 验收标准（可测） |
|---|---|
| AC1 | **命令层**：Rust 新增 **8** 个命令并全部在 `lib.rs` 的 `generate_handler!` 注册——`list_vocab(groupBy, filter)` / `add_vocab_from_token(tokenId)` / `update_vocab(vocabId, patch)` / `delete_vocab(vocabId)` / `get_vocab_by_normalized(normalized)` / `list_tags()` / `set_vocab_tags(vocabId, tagNames)` / `delete_tag(tagId)`；`api.ts` 各一层薄封装、类型来自 `types.ts`；裸 `invoke(` 除 `api.ts` 外**为 0** |
| AC2 | **收藏聚合与来源**：同一 `normalized` 从**两篇不同文章**各收藏一次 → `vocab_entry` 仍 **1 条**（`SELECT COUNT(*) WHERE normalized=?` = 1）；`surface` / `source_sentence_id` / `source_article_id` **保持首次**（第二次收藏不改这三列）；`context_meaning` 用首次收藏时的 `token_analysis.sense_in_context` 快照，**内容包后续更新不回溯改它**；`token_analysis` 不存在的词收藏成功（`context_meaning` 为 NULL） |
| AC3 | **三轴分组与筛选**：`list_vocab(groupBy, filter)` 支持 `article` / `tag` / `mastery` 三轴；按 `article` 时 `source_article_id IS NULL` 归「来源已删除」组且**排最后**；按 `mastery` 分组顺序固定 `new → fuzzy → known`；**筛选**支持 mastery 单选 + 标签多选（AND 语义）+ 关键词搜（`normalized LIKE` 或 `surface LIKE`，大小写不敏感）；空分组**不显示**（除「来源已删除」有数据时） |
| AC4 | **编辑**：`update_vocab` 可改 `context_meaning` / `phonetic` / `pos` / `mastery`（**仅这 4 列 + 标签**，见 01 §四 冲突 1）；`mastery` 非法值拒绝（DB CHECK 约束 `new/fuzzy/known`）；`set_vocab_tags(vocabId, tagNames[])` 按名字 upsert 标签（`tag.name` UNIQUE）并**全量替换**该词的标签集合；空白名/重复名去重后跳过 |
| AC5 | **点回原句**：条目「回原句」→ 跳 **`#/article/<articleId>?sentence=<sentenceId>`**（+ `&token=<tokenId>` 若有；**路径形态是 `<id>` 段，不是 `?id=`** ——`routes.tsx:92` 的 `ARTICLE_PREFIX="#/article/"` 只认路径形态，query 形态会解析出 `articleId=undefined` 并触发 `Reader.tsx:148-151`「缺文章编号」）→ 精读页滚动到该句、**高亮 2 秒后自动消退**；`source_article_id IS NULL`（来源已删）时该按钮**不显示**（不是禁用态）；`sentence` 参数指向的句子不属于该文章时**不滚动、不报错、停留原位**（fail-safe） |
| AC6 | **删除与空态**：`delete_vocab` 移除条目（`vocab_tag` 连带 CASCADE）；`delete_tag` 移除标签并连带解除关联，**生词条目不受影响**（删标签后那些词仍在，只是少一个标签）；生词本**空态**给引导文案 + 「去文章库」按钮；筛选结果为空时给「没有符合条件的生词」而非空态引导 |
| AC7 | **无障碍与不误触**：掌握状态三档**颜色不作唯一通道**（同时有文字标签，如「新词/模糊/已掌握」）；列表项与按钮可 Tab、`:focus-visible` 轮廓 >0；点击收藏按钮**不触发**词卡其它交互、**不关闭**解析面板；收藏态**一律用 `data-vocab-state`（`none`/`added`）**，**不得复用 `data-has-note`**（那个已被修复包用于「句/词有笔记」）；标签增删可键盘完成（Enter 提交、Esc 取消） |
| AC8 | **顺带收 M2 两债务（裁定 #31）**：① `useDebouncedSave` 成功回调改为 `if (PENDING_DRAFTS.get(key) === draft) delete`；② `PENDING_DRAFTS` 加 **200 条上限**（超出淘汰最旧）。两条各带**先红后绿**证据（构造能失败的用例 → 红 → 修 → 绿） |
| AC9 | **范围与红线**：只写 `vocab_entry` / `tag` / `vocab_tag` 三表（`git grep` 证明无 `INSERT/UPDATE/DELETE` 命中解析四表、内容四表、`review_plan`/`review_log`/`reading_record`）；`001_init.sql` **零改动**；不改 M1/M2 冻结契约（六个 `data-*` 属性名、`AnalysisPanel` 三态互斥、`targetKey` flush 语义）；改动全在 `02-代码/` |

## 三、具体改动点（逐条可执行）

### D0 · Rust 查询/写入层 `vocab.rs`（对应 AC1 / AC2 / AC9）
- 新增 `src-tauri/src/vocab.rs`，**复用 `commands::CommandError`**（同 crate 互引合法，M2 已审定）：
  - `list_vocab(groupBy, filter)`：一次查出条目 + 其标签（避免 N+1），按 `groupBy` 在**纯函数层**分组（Rust 只返回平铺行 + tagNames）

  - `update_vocab(vocabId, patch)`：只允许改 `context_meaning`/`phonetic`/`pos`/`mastery`，`updated_at = datetime('now')`
  - `delete_vocab(vocabId)` / `delete_tag(tagId)` / `list_tags()`
  - `set_vocab_tags(vocabId, tagNames)`：事务内「按名 upsert tag → 删除该词旧关联 → 插入新关联」（**全量替换**）
  - `get_vocab_by_normalized(normalized)`：词卡判断是否已收藏
- **消费接口**：M1 的 `token`/`token_analysis`（只读）、M0 的三张用户表；**产出接口**：8 个命令（供 D1）

### D1 · 命令注册与封装（对应 AC1）

### D2 · 纯函数层 `lib/vocab.ts`（对应 AC3）
- **`groupVocab(rows, groupBy): VocabGroup[]`**：三轴分组；`article` 轴按 `sourceArticleId` 分组、`null` 归「来源已删除」且**排最后**；`mastery` 轴固定序 `new → fuzzy → known`；`tag` 轴一个词可属多组（重复计入）；**空组不显示**
- **`matchVocab(row, filter): boolean`**：mastery 单选 + 标签多选（**AND**：全部命中才true）+ 关键词（`normalized`/`surface` 大小写不敏感包含）
- **`normalizeTagNames(raw): string[]`**：trim、去空、去重、保序
- **约束**：不依赖 DOM、不用 `enum`/`namespace`/参数属性、不 import `.css`/`.tsx`（`verify-vocab.mjs` 要 node 直 import）
- **模型类型落点**：`VocabGroup` / `VocabFilter` / `VocabCardModel` **定义并导出在 `lib/vocab.ts`**
- **消费接口**：D1 的 `VocabEntry`；**产出接口**：D3 页面 + `verify-vocab.mjs`

### D3 · 生词本页 `Vocab.tsx`（对应 AC3 / AC6 / AC7）
- 顶部：三轴切换（文章/标签/状态）+ 筛选（掌握状态、标签多选、搜索框）+ 计数
- 列表：分组标题 + 条目标题（`surface` + 音标 + 词性）+ 语境义 + 掌握状态徽标（**文字 + 颜色双重**）+ 标签 chips + 来源文章标题 + 「回原句」/「编辑」/「移出」
- 编辑：打开 `VocabEditor`（D4）
- 删除：条目「移出」二次确认（轻量，不弹原生 `confirm`）
- **空态两种**：无任何生词 → 引导文案 + 「去文章库」；筛选后为空 → 「没有符合条件的生词」
- **消费接口**：D2 纯函数、D1 的 8 封装；**产出接口**：`data-vocab-count` / `data-vocab-group` / `data-vocab-row`（供断言）

### D4 · 编辑面板 `VocabEditor.tsx`（对应 AC4 / AC7）
- 4 个字段（语境义/音标/词性/掌握状态）+ 标签编辑（输入 + Enter 添加、chip 上 × 删除、Esc 取消当前输入）
- 掌握状态三档按钮：`新词 / 模糊 / 已掌握`（文字为主，颜色辅助）
- 保存/取消；保存失败保留输入并提示重试（**不静默丢**，沿用 M2 笔记失败的教训）
- **保存后的刷新路径写死**（评审 N-6）：`onSaved(updated: VocabEntry)` 回调 → `Vocab.tsx` **用它就地替换该行 + 重拉 `list_vocab`**（标签变化会影响分组，必须重拉；只替换行会让「按标签分组」失真）
- **产出接口**：`data-vocab-editor` / `data-mastery`（供断言）

### D5 · 词卡收藏按钮（对应 AC2 / AC7）
- **数据流写死**（评审 B-2）：`AnalysisPanel` 拿 `selection.normalized` → 调 `get_vocab_by_normalized(normalized)` 得到是否已收藏 → 把 `{ normalized, vocabState, onAdd, onRemove }` 经 props 传给 `<WordCard>`。**`WordCard` 不自取数、不自己查库**（它拿不到 `normalized`）。
- `WordCard.tsx` 渲染：未收藏显示「加入生词本」（主按钮）；已收藏显示「已在生词本」+「移出」链接式按钮。
- **状态更新路径**（评审 N-6）：`created=true` → `data-vocab-state="added"`；`created=false`（已存在）同样置 `added`；移出成功后置回 `none`。**不做全量重查**（省一次 IPC）。
- 点击**不关闭**面板、不触发句子卡（沿用 `stopPropagation`）
- **不放灰色禁用按钮**（M2 立下的规矩）；`token_analysis` 不存在的词**也能收藏**（AC2 明确）
- **属性名声明**（S-R1-1 / 评审 N-3）：收藏态一律用 **`data-vocab-state`**（`none`/`added`），**不得复用 `data-has-note`**（那个已被修复包用于「句/词有笔记」）
- **消费接口**：D1 的 `get_vocab_by_normalized` / `add_vocab_from_token` / `delete_vocab`；**产出接口**：`data-vocab-state`（`none`/`added`）

### D6 · 点回原句定位（对应 AC5）
- **跳转 URL 形态（评审 B-1，务必照此写）**：`#/article/<articleId>?sentence=<sentenceId>`（+ `&token=<tokenId>` 可选）。**不是** `#/article?id=…`——`routes.tsx:92` 的 `ARTICLE_PREFIX="#/article/"` 只认路径段，query 形态会解析出 `articleId=undefined`。
- `Reader.tsx`：读 query `sentence` / `token` → 找到句节点 `[data-sentence-id="<id>"]` → `scrollIntoView({block:'center'})` + 加高亮 class **2 秒后移除**（`setTimeout` 清理，组件卸载要清）
- **query 消费时机**（评审 N-7，血泪教训）：必须在 `content` 就绪**之后**消费（`Reader.tsx:227-229` 有既有注释警告过同类问题）——内容未加载时读 query 找不到节点，会静默失效。\n- **没有既有参数冲突**（评审核实）：`Reader` 现状**不读任何 query**；M1 的 `?vis=`/`?exam=` 是 `Library` 专用，两者不在同一页面。
- **fail-safe**：找不到节点 / 句子不属于该文章 → **不滚动、不报错、停留原位**（不弹错、不跳顶部）
