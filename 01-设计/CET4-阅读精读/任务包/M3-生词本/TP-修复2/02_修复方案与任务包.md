## 一、验收标准（可测）

| 编号 | 判据 |
|---|---|
| **AC-R1** | **内容居中**：任意视口 ≥1100px 时，`getComputedStyle(.content).marginLeft/top` 左右自动边距**相等**（`marginInline:auto` 生效），文档无横向滚动条（`scrollWidth === clientWidth`）；**1920×1080 与 2560×1440 两档**各断言一次「内容左右留白差 ≤2px」 |
| **AC-R2** | **超宽屏放宽**：≥1440px 时 `.content` 的 `max-width` ≥ **1200px** 且 ≤ **1280px**；<1440px 时仍为 1100px（**不改变常规屏观感**）；正文 `.reader-body` 计算宽度**仍 ≤ 68ch 等效像素**（不许为填屏幕而拉长行） |
| **AC-R3** | **原句只有一份**：长句（> `QUOTE_LIMIT`）在卡片里**只渲染一次原文**——折叠状态下 `[data-quote-text]` 元素**数量 = 1**；展开后**仍 = 1**（不是 2）；展开前后**文本内容完全一致**；`textContent` 中不出现重复句子（断言：`textContent.split(句首词).length - 1 === 1`） |
| **AC-R4** | **折叠交互**：长句默认显示前 3 行（`-webkit-line-clamp: 3` 生效，实测 `clientHeight` ≈ 3×行高 ±20%）；点「展开全文」→ 高度变大且 `line-clamp` 失效；点「收起」→ 复原；**短句（≤ `QUOTE_LIMIT`）不出现折叠按钮** |
| **AC-R5** | **不回归**：`verify:*` 全套 + `cargo test` + `npm run build` 全绿；`check-contrast` 仍 ≥38；**CDP 原有 74 项（M2/修复1）+ 35 项（M3）判据一项不减**；六个冻结 `data-*` 属性名不变；`001_init.sql` 零改动 |

## 二、改动点（逐条可执行）

### F0 · 先实测三处宽度（不许跳过）
用 CDP 在 **1920×1080** 与 **2560×1440** 两档下读：`.content` 的 `clientWidth`/`getBoundingClientRect()`/`marginLeft`/`marginRight`、`.reader-body` 的 `clientWidth`、`.reader-split` 左列 `getBoundingClientRect().width`、右栏宽度、正文与右栏之间实际间隙。
把 6~8 个数字写入自测，**再**决定改哪里（02 01 §二 已给初判，但需实测确认次因是否存在）。
- **消费接口**：现有 CSS；**产出接口**：实测宽度表（供 F1 定值）

### F1 · `.content` 居中 + 超宽屏放宽（对应 AC-R1 / AC-R2）
- `app.css` `.content` 加 `margin-inline: auto;`（**只加这一条就能消除单侧留白**）。
- 新增媒体查询：`@media (min-width: 1440px) { .content { max-width: 1240px; } }`（值落在 1200~1280 区间，按 F0 实测微调）。
- **若 F0 实测发现正文与右栏之间存在过大空档**：把 `.reader-split` 列定义改为 `minmax(0, 66ch) 360px` + `justify-content: center`（让 grid 整体居中，而非左列吃掉全部剩余宽度）。**若空档不明显则不改**——避免无谓改动。
- **不得**修改 `.reader-body` 的 `max-width: 66ch`（正文行长是设计约束）。
- **消费接口**：F0 实测；**产出接口**：AC-R1/R2 可断言

### F2 · 「原句」改为单份 DOM + CSS 折叠（对应 AC-R3 / AC-R4）
- `SentenceCard.tsx`：把 `<details><summary>{截断}…</summary><p>{全文}</p></details>` 改为：
  ```tsx
  <div className="card-quote-body" data-quote-clamped={expanded ? "false" : "true"}>
    <p className="card-quote-text" data-quote-text>{text}</p>
  </div>
  {long ? <button type="button" className="card-quote-toggle" onClick={...}>{expanded ? "收起" : "展开全文"}</button> : null}
  ```
  —— **原文只有一份 `[data-quote-text]`**；折叠靠 CSS `-webkit-line-clamp`，展开靠切换属性/class。
- `app.css`：
  ```css
  .card-quote-body[data-quote-clamped="true"] .card-quote-text {
    display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden;
  }
  ```
  （用 `[data-quote-clamped="true"]` 而非两个 class 切换，便于 CDP 断言）
- 状态用组件内 `useState`（展开/收起），**不持久化**（换句即复位）。
- **短句**：`text.length <= QUOTE_LIMIT` 时不渲染按钮、不加 clamp 属性。
- **消费接口**：现有 `text` prop；**产出接口**：`data-quote-text`（唯一原文节点）、`data-quote-clamped`（`true`/`false`）、`data-quote-toggle`（按钮）

### F3 · 门禁与证据（对应 AC-R1~AC-R5）
- 新增/扩展 CDP 脚本（`.tmp/` 内，不入库）：AC-R1 两档居中、AC-R2 两档 max-width 与正文行长、AC-R3 唯一性、AC-R4 clamp 高度与按钮显隐、AC-R5 全量回归。
- `check-contrast` 无需新增配对（未引入新颜色）；`verify:*` 全部复跑。
- **消费接口**：F1/F2；**产出接口**：红→绿证据（改前跑一次留红，改后绿）

## 四、风险与影响面

| 风险 | 影响 | 缓解 |
|---|---|---|
| 放宽 `max-width` 后正文行长变长 | 阅读疲劳（06 #6 边注节奏） | `.reader-body` 的 `66ch` **不动**；AC-R2 断言正文宽 ≤68ch |
| `line-clamp` 在 WebView2 不支持 | 折叠失效、长句全展开 | WebView2 v156 基于 Chromium，`-webkit-line-clamp` 支持；AC-R4 用 `clientHeight` 实测而非只看 CSS 声明 |
| 折叠状态在换句后残留 | 换句仍显示「收起」 | 用 `key={sentence.id}` 或换句时 `setExpanded(false)`（AC-R4 补一条「换句后回默认收起」） |
| 改动波及 M2/修复1 已验收判据 | 回归红 | AC-R5 要求 74+35 项**一项不减** |
| `margin-inline:auto` 在 flex 容器里失效 | 居中不生效 | `.content` 是 `flex:1` 的子项，`margin-inline:auto` 在 flex row 里**有效**；F0 实测确认（若无效改用 `margin: 0 auto` 或外层 `justify-content:center`） |

**环境事实（承 M2/M3，不变）**：Node v24.21.0 / Rust 1.99.1(msvc) / `vcvars64.bat` 已知 / WebView2 v156；CDP 用 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`，用完杀进程 + 端口无残留；**在 `02-代码/` 写文件会让 vite watcher 崩 → 先改完再起 dev**。

**三问裁定**
1. **改动形态**：**3 个文件**——`src/styles/app.css`（改：`.content` 居中 + 媒体查询 + clamp 规则）、`src/components/SentenceCard.tsx`（改：原句单份 DOM + 展开态）、`.tmp/` 内 CDP 脚本（不入库）。**零 schema 改动、零新增依赖**。
2. **最便宜验证**：CDP 两档视口读 6 个数值（1~2 分钟）+ 全套 `verify:*`（秒级）+ `cargo test`（约 3s）+ `npm run build`（秒级）。**不做全量打包**。
3. **过度杀伤禁止项**：`tauri build`；截图代替机器证据；UI 框架/CSS-in-JS/新依赖；改 `001_init.sql`；改 `01-设计/`；改 `.reader-body` 的 66ch；改六个冻结 `data-*` 名；重排精读页结构（三列/侧边目录/可拖分栏）；把原句做成「预览+全文」两份。
