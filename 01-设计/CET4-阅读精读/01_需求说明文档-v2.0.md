## 二、业务背景与目标

**要解决的问题**：备考者做完一篇阅读后，想真正把文章吃透（生词、长难句、固定搭配），但工具是散的——查词要跳词典、拆句子要另外问 AI、读完就过、复盘没有结构；而市面上的解析工具质量不稳、术语不统一，且不带「自己的笔记」这一层。

**产品目标**：
1. **开箱即读**：内置真题（首期 2023-12 一套 12 篇，后续扩多年份、扩六级），打开即可精读。
2. **解析现成**：点句子出六段式解析（句译/成分/从句/短语/易错/段作用），点词出**本句语境义**，点空出逐空解析——全部人工校订、离线可查。
3. **笔记可叠**：在解析之上写自己的句笔记/词笔记，自动保存。
4. **自己的材料也能读**：用户可导入自有阅读材料（粘贴/TXT/MD），走预览→校验→入库，导入文章按「无解析降级形态」使用。
5. **有回头路**：篇级复习提醒（1/3/7/14 天）+ 生词本 + 标签 + 记录统计，让复盘不只是「读过一遍」。

**与既有替代方案的差异**（合并 docs A1 §2.3 与本项目解析能力）

| 替代方案 | 不足 | 本产品差异 |
|---|---|---|
| 手机词典 / 翻译 App | 给词典义不给语境义；来回切 App 打断阅读 | 语境义预置在 token 上，点一下即在原文出现 |
| 通用 AI 对话（问长难句） | 每句要贴文本、等生成、质量波动、离线不可用 | 解析**人工校订并预生成**，零等待、零网络、术语统一 |
| 纸质真题 + 手写笔记 | 笔记分散、生词不可检索、复盘无提醒 | 结构化到句/词粒度 + 篇级复习提醒 + 可导出 |
| 通用笔记工具（Notion/Obsidian） | 不针对精读，句/词定位弱 | 句级词级定位、生词本、复习一体化 |
| 背单词 App | 脱离语境 | 以阅读语境驱动词汇记忆 |
| 只做阅读器的工具 | 读完没有沉淀，用户材料读不了 | 笔记 + 生词 + 复习 + 自有材料导入 |

## 三、目标用户、角色与权限

- **核心用户**：
  - 备考英语四级的大学生，阅读是薄弱项，愿意花时间精读复盘；
  - **备考六级的同类需求者**（与四级同构，仅内容与筛选维度不同）；
  - **想用自己材料做精读的学习者**（学校考试阅读、外刊、其他考试真题）。
- **次要用户**：考研/雅思托福阅读训练者（结构通用，靠用户导入覆盖）。
- **角色与权限**：单一本地用户，无账号、无多角色权限，数据仅在本机。
- **非目标用户**：只想刷题看分的、要社交排行榜的、要多设备云同步的、要 AI 现生成解析的。

## 四、核心场景与现状流程

**场景 A · 精读复盘（主场景）**
打开应用 → 首页看「继续精读」或「今日待复习」→ 进文章库按**考试类型/年份/题型**筛一篇 → 原文在上、题目在下（答案折叠）→ 点不懂的句子 → 看六段式解析（翻译/主干成分/从句语法/重点短语/易错点/段落作用）→ 点不认识的词 → 看本句语境义、音标、词性、搭配、例句、是否四级高频 → 收藏进生词本 / 写词笔记 → 读完整篇生成复习计划（首次完成）。

**场景 B · 复习回看**
首页「今日待复习」列出到期文章 → 进入复习模式（复用精读页）→ 看完标记完成 → 下次间隔按 1/3/7/14 天顺延。

**场景 C · 读自己的材料**
导入页粘贴文本或选 TXT/MD → 预览：自动分段切句、显示句数与识别到的标题 → 确认入库 → 文章库「我导入的」分组 → 以**降级形态**精读：有原文与点句点词定位，但没有预置解析（显示「该篇无预置解析」，可写笔记、可收藏生词）。

**场景 D · 无网环境**
通勤/断网时全部功能可用（内容包 + 本地库 + 本地 updater 检查失败不阻塞）。

**现状流程与卡点**：用户在手机浏览器或 PDF 上看真题，遇词切词典、遇难句另开 AI，读完不做结构化复盘；卡点是切换成本高、语境义缺失、复盘无结构、自有材料无处安放。

## 七、约束

| 类别 | 约束 |
|---|---|
| 产品名 | **句读 / Judou**（`identifier`、包名、窗口标题、文档标题统一改名；越早改越省事） |
| 形态 | Tauri v2：Windows 桌面安装包 + Android APK；不提供在线 Web 服务（ADR-002） |
| 前端 | **React + TypeScript + Vite**（ADR-005）；UI 走 oil-ui 设计体系重构 |
| 后端 | Rust + rusqlite（手写 SQL、单连接 + Mutex、不用 ORM/连接池，ADR-006/007） |
| 数据 | 全部本地 SQLite 单文件；无账号、无云同步、不上传用户数据 |
| 解析数据 | **预生成内容包**（人工校订），随安装包分发；运行期零联网、零模型调用 |
| 解析粒度 | 句译/语法挂句子层；词义挂 token 层且**绑定所在句子**（同词不同句可不同解） |
| 偏移口径 | UTF-16 code unit（ADR-008；现内容包已验证 6699/6699 一致） |
| 内容范围 | 内置：2023-12 一套 12 篇（四级）；后续扩多年份、扩六级；用户可导入自有材料 |
| 用户导入 | 两阶段（preview → commit）+ 四层校验（结构/偏移/覆盖/业务）；导入文章**不预置解析** |
| 考试类型 | `cet4` / `cet6` / `other`（后续可扩） |
| 执行环境 | Windows 11 build 22621；Node 24.21.0；Rust 1.99.1；MSVC 14.44（vcvars64 已实测可用）；无 Android SDK/NDK（待补） |
| 合规 | 不做公开 UGC、不做社区分享；内置内容版权风险由用户承担（docs R01）；用户导入内容由用户自负 |
| 数据可迁移 | 迁移脚本只增不改（`001_init.sql` 发布后不动）；用户数据（笔记/生词/复习）永不因内容更新而覆盖 |

## 八、成功指标

1. 打开应用 → 首页可见「今日待复习 / 继续精读」，**点击 ≤ 2 次**进入上次阅读页。
2. 点句子 → 解析卡内容可见 **< 300ms**（本地数据）。
3. 内置文章**句子级解析覆盖率 100%**（274/274），重点词有语境义（213 张卡），选词填空 30 空全有解析。
4. Windows 安装包 **< 30MB**；冷启动到文章库可用 **< 3s**。
5. 笔记/生词/复习记录重启后**不丢失**；内容包升级不覆盖用户数据。
6. 用户导入一篇 500 词材料：从粘贴到入库完成 **< 10s**，切句结果可人工校正（预览页可改标题、可剔除空段）。
7. 复习到期准确：`next_review_at` 到期的文章在「今日待复习」出现，完成一次 `interval_index` +1。

## 九、明确不做范围

- 做题作答与判分（只展示题目与答案，选项不可点选）——ADR-012
- 运行时调用大模型生成解析——解析一律预生成、人工校订
- 账号体系、云同步、多设备、社交分享、排行榜、支付——ADR-002
- 公开 UGC 社区与内容分发——E2 边界
- 微信小程序路线（ADR-001）、Electron（ADR-004）、ORM/连接池（ADR-007）
- 在线 Web 服务与任何服务端依赖（ADR-002）
- 自动翻译/机器切词之外的 NLP 能力（词形还原 `lemma` 本期留空，ADR-009）
