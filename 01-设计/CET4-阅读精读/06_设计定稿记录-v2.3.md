## 二、决策记录

### 决策 #11 · 移除用户导入功能（彻底删）

| 项 | 内容 |
|---|---|
| **决策** | 移除**用户导入**全部能力：UI 入口、`Import.tsx`、`ArticleEditor.tsx`、4 个 Rust 文件、13 个命令、3 个门禁、39 个 fixture |
| **保留** | `import.rs` + `pack.rs` + `import_content_pack` + `verify:pack`（**内置 12 篇真题的装载通道**，删了产品就没内容） |
| **数据库** | `article.visibility` **字段保留**但收窄为单值 `system`；不做 DROP COLUMN（SQLite 限制 + 老库风险）；代码里不再有 `user` 分支 |
| **数据损失核实** | 2026-11-08 实测用户库：`article` 表 **12 行全部 `visibility='system'`，零导入文章** → 数据损失 **0** |
| **产品定位变化** | 从「CET4 精读工具 + 自定义内容」→ **「CET4 真题精读器（12 篇固定内容）」** |
| **取舍理由** | 导入的维护成本（三档需求 / 整卷多篇 / 题型容错 / 39 fixture / 3 门禁 / 约 6400 行）远超使用频率；产品价值在「对真题的精读深度」而非内容吞吐 |
| **回滚方式** | `git revert` 移除包提交即可恢复（代码在 git 历史里完整保留） |
