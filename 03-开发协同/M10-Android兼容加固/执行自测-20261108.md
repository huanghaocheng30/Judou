### D2 关键坑（已处理）

`Path::new("judou.db").parent()` 返回 `Some("")`（**空父目录**），旧代码 `parent()` 成功即 `join("exports")` → 退化回相对路径 —— 这正是 AC3 要修的形态。新内核把空父目录视同「无父目录」，继续往下退：

```rust
pub fn default_export_dir_from(db_path: &Path, app_data_dir: Option<&Path>) -> PathBuf {
    if let Some(parent) = db_path.parent() {
        if !parent.as_os_str().is_empty() { return parent.join("exports"); }
    }
    match app_data_dir { Some(dir) => dir.join("exports"), None => PathBuf::from("exports") }
}
```
