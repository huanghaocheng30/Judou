# 任务状态 · M5/TP-修复6

## 一、为什么有这个包

调度员 2026-11-07 准备 M4+M5 人工测试时实测 `npm run tauri dev` 失败：

```
Running DevCommand (`cargo  run --no-default-features --color always --`)
error: `cargo run` could not determine which binary to run. Use the `--bin` option to specify a binary, or the `default-run` manifest key.
available binaries: import_user_cli, judou
```

根因：M5 D8 新增 `[[bin]] import_user_cli` 后 crate 有两个 bin，`[package]` 无 `default-run` → Tauri dev 的 `cargo run` 无法选 bin。修法＝`default-run = "judou"` 一行（详见 `01_需求分析.md`）。
