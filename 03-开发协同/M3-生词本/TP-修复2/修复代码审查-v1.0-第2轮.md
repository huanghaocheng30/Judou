## ④ BL-1 空过排除的推理（判空过的唯一标准）

> **判据**：若把 `SentenceCard.tsx` 的 `useEffect(() => { setExpanded(false); }, [text])` **整段删掉**，这套断言会不会红？

**推理逐条**：

1. **无复位时 `expanded` 初值**：`useState(false)` → 卡片以 `clamped:"true" / 展开全文` 出现（`data-quote-clamped = long && !expanded` 派生，`long=true`）。
2. **前置 check（L323）**：先点 toggle → `setExpanded(true)` → `clamped:"false" / 收起`。**与复位逻辑无关，删 effect 照样 PASS**——它的职责只是证明「已进入展开态」，这正是旧脚本缺的一环（旧脚本 `openedBefore:"false"`，前置从未达成）。
3. **换句（L309）**：`__t2Select` 改选 `sentenceId=20` → **同一实例收到新 `text`**（`AnalysisPanel` 渲染处无 `key`，不重挂）。
   - **有 effect**：`[text]` 变 → `setExpanded(false)` → 新卡 `clamped:"true"`。
   - **无 effect**：`expanded` 保持 `true` → 新卡 `clamped:"false"`（日志实测 `atOther:{clamped:"false",toggleText:null,textHead:"Leaders should take time"}`，短句无按钮但属性仍在）。
4. **回原长句（L312）**：实例再换回 9 号句，**分歧彻底暴露**——
   - **有 effect**：`clamped:"true" / 展开全文` → **L329 PASS**（实测正是此值）。
   - **无 effect**：`expanded` 仍 `true` → `clamped:"false"` → **L329 FAIL**。
5. **L325/L327** 删 effect 时仍 PASS（换句事实、回原句事实不依赖 expanded）——它们不抓 bug，但**保证被观测的确是原长句那张卡**，排除「换句未成功导致误判」的另一类假绿。三重防护：前置保「起点真实」、`sentenceChanged/Restored` 保「对象真实」、末条保「转移真实」。

**演绎结论：会红。** 删 `useEffect([text])` 后第 4 步 `afterSwitch.clamped` 必为 `"false"`，末条（要求 `"true"`）**必然 FAIL**。

**红侧旁证**：`cdp-ac-real-red.log` 中 `BL-2 1920 正文宽 ≥652` 判 **FAIL `bodyW:498.09`**，说明脚本**在预期不满足时确实会红**，不是恒绿装饰。

> **证据等级降级声明（重要）**：上述「会红」**是源码级反事实演绎，不是变异实跑**——开发员未单独跑「删掉 effect 验红」（需改产品代码，本轮明令禁止）。按红绿纪律「未见红不算通过」，此项**不应记作与实跑同级**。据此：AC-R4 换句复位判 **pass（证据等级：部分——演绎 + 同代码红绿对照，缺变异实跑）**，本审查据此**接受通过**，但把变异实跑登记为 **D-8 / DEBT-BL1**，与 D-7 一起 M4 修 CDP 套件时补。
