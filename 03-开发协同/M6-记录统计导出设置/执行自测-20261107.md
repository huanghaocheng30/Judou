## concerns

1. **`window.open` 在 Tauri WebView2 下的真实行为未做真窗口实测**：静态断言只保证代码路径正确（`noopener` + 复制回退）。若 `window.open` 返回一个空窗口对象而非 `null`（被 CSP 拦但 API 不报错），用户会看到空白新窗口——需人工在应用内点一次「检查更新 → 下载页」确认；若确为空窗口，下一步应直接以复制通道为主（把 `window.open` 降级为可选）。
2. **`data-check-update-copy` 取值随提示状态变化**（`ready` / `copied`）：若有外部测试脚本按固定值断言该属性，需知道它是个状态值而不是常量。
3. **视觉验收全部靠静态样式断言**：AC1~AC3 的断点（1100px / 640px）、hover、淡化程度只证明 CSS 规则存在，实际观感（尤其深色主题下的描边对比度）需人工抽查。
4. **`.settings-section` 挂在全部 6 张卡上**：其中导出卡是三元素的三元式（`"card card-focus settings-section"` / `"card settings-section"`），本轮把两个分支都补上了 —— 若后续有人按精确字符串匹配 `"card card-focus"` 会失配。
5. **PDF-7 断言被本轮修改**：属于「为让新修法通过而调整既有门禁」，有削弱门禁的风险，故采取「保留正断言 + 限定唯一允许的调用点」而非删除；请审核员重点复核这一处改动是否等价于原意图。
