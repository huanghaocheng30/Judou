## concerns

1. **`<640` 档我追加了一条 `.analysis-drawer { bottom: 56px }`**（在 `app.css` 的 `<640` media query 内）。严格说它改的是既有 class 的**使用位置**，虽不违反「既有 media query 与既有 class 规则一字未改」的硬约束（是新增规则，`.analysis-drawer` 原规则 1 个字符没动、`AnalysisPanel.tsx` 零改动），但它确实是**为底部 Tab 让步的偏移**。不做的后果是实测可见的：抽屉 `bottom:0` 会被 56px 高的 Tab 栏压住，`max-height:55vh` 的抽屉底部约 56px 内容不可见。**判据留痕**：抽屉仍由 `WIDE_QUERY` 决定是否出现、`max-height` 仍 55vh、Esc 仍可关（§三 T4 实测）；若审核员认为这属于越界，回滚点是单独删这 3 行，代价是 375px 抽屉底部被遮挡。建议保留。
2. **`npm run build` 与 `npm run tauri dev` 必须在物理路径 `E:\Judou\code` 下执行，不能在 `02-代码`（junction）下执行**。实测：在 `02-代码` 下 `npm run build` 报
