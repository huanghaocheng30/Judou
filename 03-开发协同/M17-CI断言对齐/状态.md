# 任务状态 · M17-CI断言对齐

## 问题

`verify:ci`（`scripts/check-ci.mjs`）是 M7 时代写的，断言 `ci.yml` 必须有：
- build job + 三平台 matrix（windows/macos/ubuntu）
- `npm ci` / `npm run build` / `cargo check` 步骤

- ubuntu 的 webkit2gtk 依赖

而 M17 之前的 `ci.yml` 已被重写为「16 项 Node 门禁 + cargo test」——**结构完全不同**，故 9 条断言全红。

让 `check-ci.mjs` 断言**当前真实且有意义**的约束：
1. `.github/workflows/ci.yml` 存在且可解析
2. **Node 版本 ≥ 22**（5 个门禁用 `node:sqlite`，Node 20 会崩 —— 这是刚踩过的真坑）

4. 有一个 job 跑 `cargo test`
5. 有一个 job 跑 `npm run build`
6. `.github/workflows/release.yml` **不存在**（已于 2026-11-14 18:08 删除，若有人加回来要显式说明理由）
