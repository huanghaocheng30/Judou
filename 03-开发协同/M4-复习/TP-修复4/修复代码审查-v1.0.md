const upcoming = useMemo(() => {
  const list = (data?.plans ?? []).filter((p) => p.status === "active" && p.nextReviewAt > today);

### 1.4 AC-R4 三分支穷尽且不重叠

| 分支 | 条件（源码原文） | 结果 |
|---|---|---|
| ① 早返回 | `due===0 && upcoming===0 && donePlans===0` | `data-review-empty="none"` |
| ② due空 & upcoming空（done>0） | 内层 `upcoming.length===0` | `data-review-empty="done"` |
| ②′ due空 & upcoming>0 | 内层 `upcoming.length>0` | **不显示** none/done，改 `data-review-due-empty="upcoming"` 引导 + 段落 |
| ③ due>0 | else | 照常列表 |

令 `D/U/K` 为各段长度（≥0）：`D=0∧U=0∧K=0`→①；`D=0∧U=0∧K>0`→②；`D=0∧U>0`（K 任意）→②′；`D>0`（U/K 任意）→③。**穷尽** ✅。**互斥**：①/② 由 K 分出，②/②′ 由 `U===0`/`U>0` 三元互斥，③ 由 `D>0` 与前三分开 ✅。

**痛点已解**：原「今天没有到期的复习。」/「今天的复习都做完了。」在 `U>0` 时**不再渲染**，替换为「今天没有到期的复习，**接下来的安排在下面**。」——保留事实但消除「没安排」的误读 ✅。
