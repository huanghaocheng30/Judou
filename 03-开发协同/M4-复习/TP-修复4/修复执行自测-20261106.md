## 一、F0 · 红端（改代码之前）

### 1.1 造数手段与「为什么是 SQL」

`02 §二 F0` 指定「造数据用 SQL（`UPDATE review_plan SET next_review_at='...'`）」。实施细节与原因：

- **Tauri SQL 插件不可用**：`02-代码/src-tauri/capabilities/default.json` 的 `permissions` 只有 `["core:default"]`，页面侧没有数据库权限，无法从 WebView 发 SQL。
- **应用也没有「改到期日 / 删计划」命令**：`review.rs` 的写路径只有 `mark_article_completed` / `complete_review` / `restart_review_plan`，都不接受自定义 `next_review_at`（`restart` 只把 `next` 推成 `today+1`）。所以「今天到期 / 明天 / 3 天后」这组数据只能用 SQL 摆。
- **实现**：`node:sqlite`（Node 内置，**零新依赖**）直接对 `C:\Users\huanghaocheng\AppData\Roaming\com.judou.app\judou.db` 执行 UPDATE。**前置：App 必须停**（否则 WAL 下读到旧值）。
