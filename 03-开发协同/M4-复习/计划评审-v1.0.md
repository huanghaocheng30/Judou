## ④ 问题清单

### 驳回项（硬阻塞，5 条）

- **B1 · AC4 `index=3` 终态的 `next_review_at` 未写死，且 02 内部自相矛盾**
  - 位置：L41「`status='done'`、`next_review_at` 不变（或置当天，明确写死）」 vs L115「**写死**：…`next_review_at` 置为当天」
  - 原因：§三 留双选项并自注「明确写死」= 未写死；§五 已写死「当天」。开发员读 §三、测试读 §五即各按各的。
  - 修法：删掉 L41 括号，改为与 L115 逐字一致「`newIndex >= 4` → `status='done'`、`next_review_at = today`（写死）」；AC4 L16 同步补一句。

- **B2 · 「`next_review_at = today + [1,3,7,14][newIndex]`」的 `today` 来源未定，默认读「今天」= 与 01 §四 #6 冲突**
  - 位置：AC4 L16 与 D0 L41 的 `complete_review(article_id, result)`——**签名无 `today`**
  - 原因：01 §四 #6（L45）与 02 L33 已裁定「本包取前端传 today」；但 6 个命令里只有 `get_due_reviews` 带 today。实现只能退回 SQL `date('now','localtime')` → **同包两套日期来源**，`verify-review.mjs` 的固定 today 也只能断相对差。
  - 修法：`complete_review(article_id, result, today)`；L33 后补「三个写路径命令（`mark_article_completed`/`complete_review`/`restart_review_plan`）都必须带 `today`，禁止命令内用 `date('now')` 推日期」；AC1 L13 六签名同步补齐（顺带修该行 `(articleId)` 笔误）。

- **B3 · 复习模式「隐藏什么」在 01 与 02 之间不一致，且 CSS 容器指代不明**
  - 位置：01 §四 #5 L44「隐藏笔记标记**与生词按钮**」vs 02 D4 L66 两条 CSS、L69「只影响呈现」；D4 L65「给 `<section>` 加」

  - 修法：① 择一写死（推荐**藏生词按钮**，与 01 原文一致，契合「不看提示」）；② L65 改为「给 `Reader.tsx:366` 的**根** `<section>` 加 `data-review-mode="1"`」；③ 同时写死新 CSS 用 `[data-review-mode="1"] .tok[data-has-note="1"]`（0,3,1）并置于 `app.css:1141` 之后。

- **B4 · AC5「已完成今日态」与 AC7「`done` 可重启」的数据源不可达**
  - 位置：AC5 L17；D3 L59-61（含「已在 `status='done'` 的文章提供『重新加入复习』」）；AC7 L19
