## 三、顺延规则口径（易错点，写死在此）

`interval_index` = **已完成次数**；`done` 时 `newIndex = index + 1`，然后取 `INTERVALS[newIndex]`：

| 完成前 index | 动作 | 完成后 index | `next_review_at` |
|---|---|---|---|
| 0 | done | 1 | today + **3**（`INTERVALS[1]`） |
| 1 | done | 2 | today + **7**（`INTERVALS[2]`） |
| 2 | done | 3 | today + **14**（`INTERVALS[3]`） |
| 3 | done | 4 | **today**（终态 `status='done'`，写死） |
| 任意 | need_more | 不变 | today + **1** |

首次建计划（`mark_article_completed` / `restart` 的 INSERT 分支）是 `next_review_at = today + 1`、`index = 0`。
Rust `due_filter_order_and_four_step_advance` 与 TS `E-3/E-4` 用**同一组用例**（today=2026-11-06）逐项对齐。
