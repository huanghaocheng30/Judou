**附加：继承的窄竞态（非本轮引入，medium · 承重）**

- **位置**：`useDebouncedSave.ts:123` `PENDING_DRAFTS.delete(key)` **无条件**。
- **链条**：`saveNow(A)` in-flight → 用户继续输入 → `change` 写入 pending=B + 新 timer → 旧请求成功 → `delete(key)` **删掉 B** → 新 timer 到点 `PENDING_DRAFTS.get(key)` 为 `undefined`（`:156-157`）→ **B 不落库**；UI 最终显示 `saved`；切走/切回后 `reset` 用库值覆盖 → 当次新输入丢失。
- **可达窗口**：invoke 往返（本地 SQLite，毫秒级）+ 必须在 800ms timer 已触发后继续输入 → **极窄**。
- **是否本轮回归**：**否**——旧版 `dirtyRef.current = false` 在成功回调同样无条件清（diff 删除行），timer 回调 `if (dirtyRef.current)` 同样不保存 → **同构继承**。
- **为何仍登记**：本轮把草稿身份从 boolean 改为 Map 后，修法成本降到 **1 行**：`if (PENDING_DRAFTS.get(key) === draft) PENDING_DRAFTS.delete(key);`（引用比较）。→ **债务 D-M2-11 / 建议 S-11**；**不驳回**（不构成本轮修复的回归，AC8-f 目标场景未被破坏）。
