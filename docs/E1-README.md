## 这是什么

**cet4-reader**
是一个面向英语四级备考的**阅读精读工作台**。它的核心闭环是：

    选/导文章 → 读原文 → 点句点词写笔记 → 收藏生词 → 按篇复习 → 看记录

它不替你生成解析，而是给你一个顺手的容器：你点一句话，写自己的翻译和语法笔记；你点一个单词，写它在这句话里的意思，加入生词本；读完之后，系统按篇提醒你回来复习，之前写的笔记和高亮都还在。

产品定位是**工具**，不是内容平台，也不是 AI 解析器。

## 核心功能

### 精读

- 原文按段落展示，**句子和单词可精确点击**。
- 点句子：写句译、语法笔记、短语笔记。
- 点单词：写语境释义、搭配、例句，一键加入生词本。
- 有笔记的句子、已收藏的单词有视觉标识。
- 笔记自动保存，重启不丢。

### 生词本

- 按单词聚合，记录语境释义、来源句、来源文章。
- 支持标签、掌握状态（未掌握 / 模糊 / 已掌握）。
- 可导出打印友好的 HTML，用浏览器打印为 PDF。

### 复习

- 完成精读后自动生成篇级复习计划，默认间隔 **1 / 3 / 7 / 14 天**。
- 首页显示"今日待复习"，点进去重新精读，笔记原样呈现。
- "已复习"推进间隔，"还需再看"次日再提醒。

### 导入

- 支持粘贴文本、上传 `.txt` / `.md`。
- 自动清洗、分段、切句、分词，预览确认后入库。
- 导入的文章默认私有，可删除。

### 记录

- 已读篇数、精读中、待复习、生词数、笔记数、复习次数。
- 阅读记录、复习历史可查看、可跳转。

### 跨平台

- **桌面端**：Windows / macOS / Linux，Tauri v2 构建，安装包小。
- **Android**：APK 安装，后续版本支持。
- **自动更新**：桌面端支持应用内检查并安装更新。

## 它不是什么

为了避免误解，明确列出**不做**的事：

- **不是 AI 解析器**：平台不生成句译、语法、词义，笔记由你自己写。
- **不是题库 / 刷题 App**：第一版不做作答判分，只展示题目和答案。
- **不是单词卡 App**：复习以整篇文章为单位，不是纯单词间隔重复。
- **不是内容平台**：不做公开社区、分享、排行榜。
- **不是在线服务**：不提供在线 Web 版，不需要注册账号，数据不上传。
- **不是小程序**：不做微信小程序。

## 安装

### 桌面端

从 [GitHub Releases](../../releases) 下载对应平台的安装包：

  平台      文件
  --------- --------------------------------------
  Windows   `.msi` 或 `.exe`
  macOS     `.dmg`（Intel + Apple Silicon 通用）
  Linux     `.AppImage` 或 `.deb`

**macOS 用户注意**：当前版本未配置 Apple
代码签名和公证。首次打开可能提示"无法验证开发者"，需要在"系统设置 →
隐私与安全性"中手动放行。

### Android

从 [GitHub Releases](../../releases) 下载 `.apk`
安装。需要允许"安装未知来源应用"。

Android 端**不支持应用内静默更新**。检查到新版本后，会引导你到 Release
页面手动下载 APK 安装。

### 更新

- **桌面端**：应用启动时自动检查更新，或在设置页手动检查。
- **Android**：设置页手动检查，跳转 Release 页面下载。

## 使用

### 第一次使用

1.  打开应用，首页会展示引导：点句子写笔记、点单词加生词本、按篇复习。
2.  从文章库选一篇文章，或点击"导入"粘贴自己的材料。
3.  进入精读页，点击任意句子开始写笔记。

### 精读一篇

1.  在文章库选择文章，进入精读页。
2.  读原文，遇到不理解的句子点一下，在底部面板写翻译和语法笔记。
3.  遇到生词点一下，写语境释义，点"加入生词本"。
4.  读完点击"完成精读"，系统生成复习计划。

### 复习

1.  首页或复习页显示"今日待复习 N 篇"。
2.  点进某篇，进入复习模式，本篇笔记高亮显示。
3.  快速过一遍，点击"已复习"或"还需再看"。

### 导入自己的文章

1.  点击"导入"，粘贴正文或上传 `.txt` / `.md`。
2.  填写标题（可选来源、题型）。
3.  点击"预览"，查看分段和切句是否合理。
4.  确认导入，文章出现在"我的导入"。

**导入前请确保你对导入内容拥有合法使用权。**
本工具仅在你本地处理内容，不上传、不分发、不审核。

### 导出生词本

1.  进入生词本，点击"导出"。
2.  选择导出范围（全部 / 按文章 / 按标签 / 未掌握）。
3.  生成打印友好 HTML，用浏览器打开后打印为 PDF。

## 数据与隐私

- **所有数据存在本地**：文章、笔记、生词、复习记录全部存在你设备上的
  SQLite 数据库。
- **无账号、无登录**：不需要注册，不收集任何个人信息。
- **不上传、不联网**（除检查更新）：应用不向任何服务器发送你的数据。
- **数据由你备份**：项目维护者无法访问、恢复或备份你的本地数据。建议定期用导出功能备份。

数据库位置由操作系统应用数据目录决定：

  平台      路径
  --------- -----------------------------------------------------
  Windows   `%APPDATA%\<identifier>\app.db`
  macOS     `~/Library/Application Support/<identifier>/app.db`
  Linux     `~/.local/share/<identifier>/app.db`
  Android   应用私有目录

## 从源码构建

### 前置依赖

- Rust（stable，通过 [rustup](https://rustup.rs) 安装）
- Node.js LTS（20 或 22）
- 各平台系统依赖：
  - **Windows**：Microsoft C++ Build Tools、WebView2
  - **macOS**：Xcode Command Line Tools
  - **Linux**：`libwebkit2gtk-4.1-dev`、`libappindicator3-dev`、`librsvg2-dev`、`patchelf`

Linux 依赖安装：

``` bash
sudo apt-get update
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
```

### 构建

``` bash
# 克隆仓库
git clone https://github.com/<owner>/<repo>.git
cd <repo>

# 安装前端依赖
npm install

# 开发模式（热更新）
npm run tauri:dev

# 构建当前平台安装包
npm run tauri:build
```

产物位于 `src-tauri/target/release/bundle/`。

### 测试

``` bash
# Rust 单元测试
cd src-tauri && cargo test

# 前端测试
npm test
```

### Android 构建

需要额外安装 JDK 17+、Android SDK、NDK，并配置
`ANDROID_HOME`、`NDK_HOME`。详见 `docs/D2-开发环境与项目结构.md`。

``` bash
cargo tauri android init
cargo tauri android build
```
