## 1. 文档说明

### 1.1 目的

把 A1 定义的产品闭环拆成可实现、可验收的功能规格，让开发（含 AI 编码代理）不需要反复猜测“这个按钮点了应该怎样”。

### 1.2 范围

覆盖 MVP 全部页面与功能。二期功能只在“未来扩展”中列出，不进入本期验收。

### 1.3 读者

- 产品/开发本人：作为实现依据。
- AI 编码代理：作为 `AGENTS.md` 之外的业务规则补充。
- 测试：作为验收用例来源。

---

## 2. 用户角色

MVP 只有一类角色：**本地单用户**。无账号、无登录、无多用户切换。

| 角色 | 说明 | 权限 |
|---|---|---|
| 本地用户 | 安装应用的考生 | 读写本机全部数据；可导入/删除自己的文章；不可删除系统文章 |

**系统**：内置文章、种子数据、复习计划生成规则，由应用内部维护，用户不可直接编辑。

## 5. 核心流程

### 5.1 精读流程

```
进入精读页
→ 加载原文、题目、已有笔记
→ 用户阅读原文
→ 点句子 → 底部面板打开 → 编辑句译/语法/短语 → 自动保存
→ 点单词 → 底部面板打开 → 编辑释义/搭配/例句 → 可加入生词本
→ 返回或点“完成精读”
→ 记录阅读进度；首次完成时生成复习计划
```

### 5.2 导入流程

```
进入导入页
→ 粘贴正文或上传 TXT/MD
→ 填写标题（可选来源/题型）
→ 点击“预览”
→ 系统清洗、分段、切句、分词
→ 用户预览句子边界，可合并/拆分句子（P1）
→ 点击“确认导入”
→ 校验 + 入库
→ 成功：跳转精读页；失败：定位错误
```

### 5.3 复习流程

```
首页/复习页显示“今日待复习 N 篇”
→ 点进某篇 → 进入精读页的复习模式
→ 高亮本篇笔记过的句子和单词
→ 用户重新精读，可继续编辑笔记
→ 点击“已复习”或“还需再看”
→ 推进复习计划；记录复习日志
```

### 5.4 导出流程

```
进入生词本
→ 选择导出范围（全部/按文章/按标签/未掌握）
→ 点击“导出”
→ 系统生成打印友好文件
→ 打开文件或另存为
```

## 6. 功能详细规格

### F1 文章库

#### F1.1 页面目的

让用户找到要精读的文章，区分系统文章和自己的导入。

#### F1.2 页面元素

- 顶部：标题“文章库”、搜索框、筛选按钮。
- Tab 或分段控件：**内置文章 / 我的导入**。
- 筛选条件：
  - 内置文章：年份、套卷、题型（选词填空/长篇阅读/仔细阅读）、难度、状态。
  - 我的导入：状态、导入时间排序。
- 文章卡片：标题、来源、题型、词数、状态标签（未读/精读中/已完成/待复习）、生词数。
- 我的导入卡片额外有“删除”操作。

#### F1.3 交互规则

1. 默认展示“内置文章”，按年份倒序、套卷顺序、题型顺序排列。
2. 搜索按标题模糊匹配，实时过滤。
3. 筛选条件可多选组合，有“重置”按钮。
4. 点击卡片进入精读页。
5. 我的导入文章可删除，删除前二次确认，提示“删除后该文章的笔记和生词引用将一并删除”。
6. 系统文章不显示删除入口。
7. 空状态：内置文章为空时显示“内容准备中”；我的导入为空时显示“导入你的第一篇文章”按钮。

#### F1.4 状态与异常

| 情况 | 表现 |
|---|---|
| 加载中 | 骨架屏 |
| 加载失败 | 错误提示 + 重试按钮 |
| 搜索无结果 | “没有找到相关文章” + 清空搜索 |
| 删除失败 | toast “删除失败，请重试” |

#### F1.5 验收标准

- [ ] 内置文章与我的导入分 Tab 展示，互不混杂。
- [ ] 筛选、搜索、重置可用，组合筛选结果正确。
- [ ] 文章状态标签随阅读进度正确变化。
- [ ] 我的导入可删除，系统文章无删除入口。
- [ ] 空状态、加载态、错误态均有对应展示。

### F2 精读页

#### F2.1 页面目的

核心学习页面。用户在这里读原文、写句笔记、写词笔记、加入生词本。

#### F2.2 页面结构

```
顶部栏：返回 | 标题 | 进度/完成按钮
正文区：按段落展示原文，句子可点击，单词可点击
题目区（可折叠）：题干 + 选项 + 答案（折叠）
底部面板（点击句子或单词后弹出）：笔记编辑区
```

#### F2.3 原文展示规则

1. 按段落展示，段间距明显。
2. 句子是**可点击单元**，点击后整句高亮，底部面板打开。
3. 单词是**可点击单元**，点击后该词高亮，底部面板打开。
4. **已写笔记的句子**：句子下方显示浅色下划线或左侧色条。
5. **已加入生词本的单词**：单词下方显示浅色下划线。
6. **当前选中的句子/单词**：高亮背景色。
7. 复习模式下，额外高亮“本篇有笔记的句子和单词”。

#### F2.4 题目区规则

1. 题目区默认折叠，标题显示“题目（N）”。
2. 展开后显示题干和选项，选项**不可选择**（不做判分）。
3. 答案默认折叠，点击“查看答案”展开。
4. 答案区显示答案和可选解析文本（来自文章数据）。
5. 题目区不记录用户作答行为。

#### F2.5 句笔记面板

点击句子后从底部弹出（移动端）或右侧滑出（桌面端）。

**字段：**

| 字段 | 类型 | 说明 |
|---|---|---|
| 原句 | 只读 | 当前句子文本 |
| 句译 | 多行文本 | 用户写的中文翻译 |
| 语法笔记 | 多行文本 | 用户写的语法点 |
| 短语笔记 | 多行文本 | 用户写的短语/固定搭配 |
| 操作 | 按钮 | 保存状态提示、关闭 |

**规则：**

1. 三个字段均为自由文本，不做格式校验。
2. 输入防抖 500–800ms 自动保存，面板顶部显示“已保存/保存中/保存失败”。
3. 关闭面板不丢内容；重新打开同一句，内容回显。
4. 面板可拖动展开/收起（移动端），桌面端固定宽度。
5. 保存失败时保留本地草稿，显示“重试”按钮。
6. 复习模式下，面板默认展示已有笔记，可直接编辑。

#### F2.6 词笔记面板

点击单词后弹出。

**字段：**

| 字段 | 类型 | 说明 |
|---|---|---|
| 单词 | 只读 | 原文形态 + 小写形式 |
| 音标 | 文本（P1） | 用户可填，MVP 可留空 |
| 词性 | 文本（P1） | 用户可填 |
| 语境释义 | 多行文本 | 用户写的在这句话里的意思 |
| 搭配 | 多行文本 | 用户写的搭配/固定用法 |
| 例句 | 多行文本 | 用户自己写的例句 |
| 加入生词本 | 按钮/开关 | 加入后按钮变为“已在生词本” |

**规则：**

1. 字段均为自由文本，不做校验。
2. 自动保存规则同句笔记。
3. 点击“加入生词本”后：
   - 若该词（按 normalized 聚合）已在生词本，提示“已在生词本”，不重复添加，可跳转查看。
   - 若不在，创建生词条目，携带当前语境释义、来源句、来源文章。
4. 加入生词本后，原文中该词显示生词下划线。
5. 从生词本移除后，下划线消失，但已写的词笔记保留。

#### F2.7 阅读进度与完成

1. 滚动位置或已点击句子数用于计算进度，进度条显示在顶部。
2. 用户点击“完成精读”：
   - 记录 `completed_at`。
   - 若该文章尚无复习计划，生成默认计划（1/3/7/14 天）。
   - 状态变为“已完成”。
3. 完成精读不要求必须写笔记，但若笔记数为 0，弹轻提示“还没有写笔记，确定完成吗？”（可关闭，不阻断）。
4. 已完成文章再次进入，仍可编辑笔记，不重置复习计划。

#### F2.8 状态与异常

| 情况 | 表现 |
|---|---|
| 文章不存在 | “文章不存在或已删除” + 返回 |
| 加载失败 | 错误提示 + 重试 |
| 笔记保存失败 | 面板内提示 + 重试，本地草稿保留 |
| 生词添加失败 | toast “添加失败，请重试” |
| 离线 | 本地应用，无离线概念；数据库异常按保存失败处理 |

#### F2.9 验收标准

- [ ] 原文按段落展示，句子和单词可精确点击。
- [ ] 点击句子弹出句笔记面板，三个字段可编辑并自动保存。
- [ ] 点击单词弹出词笔记面板，字段可编辑并自动保存。
- [ ] 加入生词本后原文有标识，重复添加有提示。
- [ ] 已写笔记的句子、已加入生词本的单词有视觉标识。
- [ ] 题目区默认折叠，选项不可选，答案可展开。
- [ ] 关闭应用重启后，笔记和生词不丢。
- [ ] 点击“完成精读”生成复习计划，状态更新。
- [ ] 复习模式下高亮本篇笔记，可继续编辑。

### F3 生词本

#### F3.1 页面目的

集中管理用户收藏的生词，支持编辑、标签、掌握状态和导出。

#### F3.2 页面元素

- 顶部：标题“生词本”、搜索框、筛选、导出按钮。
- 统计条：总词数、已掌握、未掌握。
- 列表项：单词、音标（可选）、词性（可选）、语境释义、来源文章、标签、掌握状态。
- 列表操作：点击进入编辑、左滑/右键删除。

#### F3.3 筛选与排序

- 筛选：全部 / 未掌握 / 模糊 / 已掌握；按文章；按标签。
- 排序：添加时间倒序（默认）、字母序。
- 搜索：按单词模糊匹配。

#### F3.4 编辑生词

**可编辑字段：** 音标、词性、语境释义、搭配、例句、标签、掌握状态。

**规则：**

1. 编辑自动保存，规则同笔记。
2. 掌握状态三档：`new`（未掌握）/ `fuzzy`（模糊）/ `known`（已掌握）。
3. 标签可多选，支持新建标签。
4. 删除生词需二次确认，删除后原文中的生词标识消失，但词笔记保留。

#### F3.5 导出

1. 点击“导出”，弹出导出范围选择：
   - 全部
   - 当前筛选结果
   - 按文章
   - 按标签
   - 仅未掌握
2. 选择后生成**打印友好文件**（MVP 用 HTML，浏览器打印为 PDF）。
3. 文件内容：标题、导出时间、筛选条件、单词表。
4. 单词表列：单词、音标、词性、语境释义、搭配、原句、来源文章。
5. 生成成功后提示“已生成，是否打开”，打开系统默认浏览器或文件管理器。
6. 生成失败提示重试。

#### F3.6 验收标准

- [ ] 生词列表展示完整字段，支持搜索、筛选、排序。
- [ ] 生词可编辑，自动保存，重启不丢。
- [ ] 掌握状态可切换，筛选结果正确。
- [ ] 标签可创建、绑定、筛选。
- [ ] 删除生词有二次确认，删除后原文标识消失。
- [ ] 导出范围可选，生成文件内容完整、可打印。
- [ ] 重复添加同一单词不产生重复条目。

### F4 复习

#### F4.1 页面目的

按篇提醒用户复习，而不是只刷单词卡。

#### F4.2 复习计划规则

1. 文章首次“完成精读”时自动生成计划。
2. 默认间隔：**1 天、3 天、7 天、14 天**，共 4 次。
3. 用户可在设置中修改默认间隔（P1），或对单篇调整（P1）。
4. 每次完成复习，推进到下一个间隔；完成第 4 次后状态为 `done`。
5. 用户选择“还需再看”时，**不推进间隔**，下次复习时间设为次日。
6. 计划可暂停/恢复（P1）。

#### F4.3 今日待复习

1. 首页和复习页展示“今日待复习 N 篇”。
2. 列表项：文章标题、上次复习时间、当前间隔序号、笔记数。
3. 点击进入精读页的**复习模式**。
4. 今日无待复习时显示“今天没有待复习的文章” + 推荐新文章。

#### F4.4 复习模式

1. 复用精读页，顶部显示“复习中”标识。
2. 高亮本篇所有有笔记的句子和已加入生词本的单词。
3. 用户可正常点击句子/单词查看和编辑笔记。
4. 底部固定操作栏：“已复习” / “还需再看”。
5. 点击后记录复习日志，更新计划，返回复习列表。
6. 复习模式不要求重写笔记，不要求完成所有句子。

#### F4.5 验收标准

- [ ] 完成精读后自动生成 1/3/7/14 天计划。
- [ ] 今日待复习列表按到期时间正确展示。
- [ ] 复习模式高亮本篇笔记，可正常编辑。
- [ ] “已复习”推进间隔，“还需再看”不推进且次日再提醒。
- [ ] 完成 4 次后不再出现在待复习列表。
- [ ] 复习历史可在记录页查看。

### F5 导入

#### F5.1 页面目的

让用户导入自己的文章，经过切句分词后进入精读。

#### F5.2 输入方式

**MVP 支持：**

1. 粘贴纯文本。
2. 上传 `.txt`。
3. 上传 `.md`。

**MVP 不支持：** `.docx`、`.pdf`、OCR、网页抓取、图片。

#### F5.3 输入表单

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 | 是 | trim 后非空 |
| 正文 | 是 | 粘贴或文件内容 |
| 来源 | 否 | 自由文本 |
| 题型 | 否 | 默认“自定义” |
| 难度 | 否 | 默认“自定义” |
| 题目 | 否（P1） | MVP 可先不做题目录入，只精读正文 |

#### F5.4 预览规则

1. 点击“预览”后调用解析，展示：
   - 清洗后的标题（若首行是 `# 标题` 自动提取）
   - 分段结果
   - 每段的句子切分
   - 警告提示（如“未检测到空行，已作为单段”）
2. 用户可查看切句是否合理。
3. **P1**：允许用户合并/拆分句子；MVP 先只读展示，提供“重新解析”按钮。
4. 预览页显示“确认导入”和“返回修改”。

#### F5.5 确认导入规则

1. 点击“确认导入”调用 commit。
2. 成功后跳转精读页，toast “导入成功”。
3. 失败时按错误类型提示：
   - 标题为空：定位到标题输入框。
   - 偏移错误：提示“解析异常，请重试或调整文本”。
   - 数据库错误：提示“保存失败，请重试”。
4. 导入的文章出现在“我的导入”，`visibility = user`。
5. 重复导入同一篇不自动去重，生成新文章；P1 可加相似提示。

#### F5.6 验收标准

- [ ] 粘贴、TXT、MD 三种输入方式可用。
- [ ] 标题必填校验生效。
- [ ] 预览正确展示分段和切句，异常有警告。
- [ ] 确认导入后文章出现在“我的导入”，可进入精读。
- [ ] 导入失败有可理解的错误提示，不产生脏数据。
- [ ] 导入文章可删除，删除后相关笔记和生词引用按规则清理。

### F6 记录与统计

#### F6.1 页面目的

让用户看到自己的学习资产和进度。

#### F6.2 内容

1. **概览卡片**：已读篇数、精读中、待复习、生词数、笔记数、复习次数。
2. **阅读记录列表**：文章标题、状态、最后阅读时间、笔记数、复习次数。
3. **复习历史**：文章、复习时间、结果（已复习/还需再看）。
4. **薄弱提示（P1）**：高频点击但未加入生词本的词、笔记最少的已读文章。

#### F6.3 规则

1. 统计口径来自本地数据库，实时计算或简单缓存。
2. 列表支持按时间倒序，分页或滚动加载。
3. 点击记录进入对应文章精读页。

#### F6.4 验收标准

- [ ] 概览数字与数据库一致。
- [ ] 阅读记录、复习历史可查看，可跳转。
- [ ] 空状态有引导文案。

### F7 设置

#### F7.1 内容

1. **复习间隔**（P1）：修改默认 1/3/7/14 天。
2. **数据备份/导出**（P1）：导出 SQLite 数据库文件或 JSON 备份；导入恢复。

#### F7.3 验收标准

- [ ] 数据备份可导出、可恢复，恢复前有确认。
- [ ] 关于页信息完整。
- [ ] 手动检查更新可用。

### F8 首次引导

#### F8.1 目的

解决“用户自己写笔记，第一篇不知道怎么用”的冷启动问题。

#### F8.2 规则

1. 首次启动展示 3 步引导：
   - 点句子写笔记
   - 点单词加入生词本
   - 按篇复习
2. 引导可跳过，不重复展示。
3. 第一篇文章精读页展示轻提示气泡：“点击任意句子开始写笔记”，用户首次点击句子后消失。
4. 内置文章可预置一篇“示例文章”，带少量示例笔记，标注“示例”，用户可清除。

#### F8.3 验收标准

- [ ] 首次启动展示引导，可跳过。
- [ ] 引导只展示一次。
- [ ] 精读页首次点击提示正常出现和消失。
- [ ] 示例笔记可识别、可清除。

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 精读页首屏加载 < 1s（本地数据）；点击句子/单词面板响应 < 100ms；笔记保存 < 500ms |
| **数据安全** | 笔记自动保存 + 本地草稿兜底；应用异常退出不丢已保存内容 |
| **兼容** | Windows 10+、macOS 12+、Linux 主流发行版、Android 8+ |
| **可用性** | 核心操作不超过 3 步；移动端单手可完成点句/点词 |
| **无障碍（P1）** | 关键按钮有可读标签；颜色对比度达标 |
| **隐私** | 不收集用户数据；不联网（除检查更新）；导入内容不上传 |
| **体积** | 安装包尽量小（Tauri 优势）；不打包大体积静态资源 |

## 8. 边界与异常汇总

| 场景 | 处理 |
|---|---|
| 文章被删除但生词引用存在 | 生词保留，来源文章显示“已删除” |
| 句子笔记保存时句子已被删除 | 返回错误，提示刷新 |
| 导入文本为空 | 阻止预览，提示“正文不能为空” |
| 导入文本超长（如 > 100KB） | 提示“文本过长，建议拆分导入”（P1 限制） |
| 数据库文件损坏 | 启动时提示，引导从备份恢复 |
| 自动更新下载失败 | 提示手动到 Release 下载，不阻塞使用 |
| 用户快速连续点击导入 | 按钮 loading 期间禁用，防重复提交 |

## 9. 埋点与统计口径

**本项目不做服务端埋点**，所有统计为本地计算，用于记录页展示，不上传。

| 指标 | 本地口径 |
|---|---|
| 精读完成率 | 已完成文章数 / 已打开文章数 |
| 句子点击率 | 有句子笔记的文章数 / 已读文章数 |
| 单词收藏率 | 生词数 / 点击过的单词数（P1 需记录点击） |
| 复习完成率 | 已复习次数 / 到期复习次数 |
| 笔记数 | sentence_note + word_note 记录数 |
| 生词数 | vocab_entry 记录数 |
