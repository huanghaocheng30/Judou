## 一、怎么启动（一条命令）

在 `E:\Judou\02-代码\` 下：

```
npm run tauri dev
```

- 第一次编译 Rust 大概 1~3 分钟，之后几十秒。
- 应用窗口会自己弹出（标题是「句读」）。
- **第一次启动会自动把 12 篇真题导进本地库**（耗时约 0.3 秒），控制台会打一行 `imported: 12, skipped: 0`。第二次启动打 `imported: 0, skipped: 12`（不重复导入）。
- 想从零开始：先关掉应用，删掉 `%APPDATA%\com.judou.app\judou.db`，再启动。

> 本轮**不提供安装包**（.exe）——打包归最后一个包（M7）。现在测的是源码运行版，功能与将来的安装版一致。

## 二、这次新增了什么

上一个包（M0）交付的是空壳：8 个页面全是占位，库里有表没数据。

这一包之后，产品**第一次能读**：

1. **文章库有货了**——12 篇 2023 年 12 月 CET-4 真题，分成 3 套 × 4 篇（每套：仔细阅读 2 篇 + 长篇阅读 1 篇 + 选词填空 1 篇）
2. **能筛能搜**——考试类型 / 年份 / 题型 / 来源，可组合；标题搜索；筛选状态写进网址，刷新后还在
3. **能点进去读**——逐段逐句的原文、空格位置、题目（折叠）
4. **能返回**——回到文章库，筛选条件不丢

**还不会有的**（下一个包 M2 才做）：点句子出解析卡、点词出词卡、题目能选答案、笔记。

## 三、请你重点看这 8 条（都能一眼验）

打开应用 → 左侧「文章库」：

1. **12 张卡**，每张写着：篇名 / 年份（2023）/ 题型（仔细阅读·长篇阅读·选词填空）/ 词数 / 句数。
2. **筛选器有 4 个**：考试类型、年份、题型、**来源**（应显示 `CET-4 2023年12月真题`）。随便组合两个，列表应该变少；点「清除筛选」应该回到 12 篇。
3. **搜索**框输入 `busy` → 应该只剩 1 篇（*Why We Are So Proud to Say We're Busy*）；输入 `Rival` → 1 篇。清空恢复 12 篇。
4. **刷新页面（F5）**：筛选和搜索条件应该还在（它们被写进了地址栏的 `?vis=...&exam=...`）。
5. **点进任意一篇** → 精读页：
   - **句子和句子之间应该有一个空格，不能粘在一起**（这是上一轮审查抓到、这轮修好的缺陷——请重点看：正常英文句子之间要有空格，不该出现 `word.First`、`word.The` 这种连体）
   - 正文宽度约 66 个字符、居中，读起来像书页
   - **选词填空那篇**（标题含 `Exercising`）正文里的 `26`~`35` 是**空格位**，应该有特殊样式；而正文里本来就有的 `150`、`1997`、`88,000` 这些数字**不该**被当成空格
6. **题目区默认是折叠的**，点开能看到题干和选项；**点选项应该没反应**，也**看不到答案是哪个字母**（这是 M2 才给的交互）。
7. **点返回** → 回到文章库，**原来的筛选还在**。
8. 切到「我导入的」分组 → 应该显示引导文案（「还没有导入材料 → 去导入」），列表是空的。M5 才接真正的导入。

另外顺手验两个：

- **主题切换**（右上角）：浅色 / 深色 / 跟随系统，标签（`.tag`）的字在浅色下**要看得清**——这是上个包遗留的对比度缺陷，这一包修好了。
- **坏包演练（可选，稍微折腾）**：把 `E:\Judou\02-代码\content-pack\manifest.json` 改成一个坏文件（比如写 `{`），重启应用 → 应该**弹出一个整页错误页**写着「内容包损坏 / `manifest.json` / 请重新安装」，**而不是**进入一个空空如也的文章库；**应用不能闪退**。看完记得把 `manifest.json` 还原（用 `git checkout -- 02-代码/content-pack/manifest.json`）。
