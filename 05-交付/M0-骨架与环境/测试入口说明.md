## 二、启动方式


**怎么关**：直接关窗口，或在终端按 `Ctrl+C`。**关掉后请确认没有残留进程**（下面 §四 有检查命令）。

## 三、要测什么（建议按此顺序，10 分钟内可完成）

### ① 能启动、壳对不对（AC1）
- 窗口标题是**「句读」**（不是 "Tauri App"、不是 "judou"）。
- 左侧边栏 **7 项**：今日 / 文章库 / 复习 / 生词本 / 导入 / 记录 / 设置。
- 逐个点过去：每页都显示占位文案（如「内容导入将在 M1 接入」），**没有空白页、没有报错**。
- 终端里没有红色 panic，页面按 F12 看 Console 没有报错。

### ② 主题三档（AC4）——本包最值得看的交互
- 进「设置」页，点 **浅色 / 深色 / 跟随系统** 三段控件。
- 每点一次，整窗配色应**立即变化**（不等刷新）。
- 选中项应有明确视觉区分（浅陶土底 + 墨字加粗 + 一圈细描边）。
- 选「跟随系统」后，去 Windows 设置里切系统深/浅色，窗口应跟着变。
- **关掉应用再启动**，应保持你上次选的档位。

### ③ 图标（AC5）
- 窗口左上角 / 任务栏图标应是**句读的四线图标**，不是 Tauri 默认的橙红方块。
- （安装向导、开始菜单项归 M7 测，本包不做安装包。）

### ④ 数据落库（AC2，间接看）
- 首次启动会自动建库：`%APPDATA%\com.judou.app\judou.db`
- 想验证「首次启动建库」这一步：**先关掉应用，删掉这个 db 文件，再启动**，应能正常起来并重建（不报错、界面正常）。

### ⑤ 一句话能说明白的边界（不是缺陷）
- **没有文章、没有解析、没有复习、没有生词**——这是 M0 的预期，M1 才导内容。
- 8 个页面全是占位，只有「设置」页有真交互（主题切换）。

### ⑥ 已知小瑕疵（不阻塞，已登记 D-M0-6）
- 占位页上那个小标签（如「M1」）在**浅色**主题下字偏淡（对比度 3.73:1，标准 4.5:1）；深色下正常。
- 修法已定（1 行），安排在 **M1 开工前**收口。你若觉得现在就想修，说一声即可。
