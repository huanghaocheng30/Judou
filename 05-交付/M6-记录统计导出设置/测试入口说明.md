## 二、重点：导出 PDF 词表（**先验这个**）

路径：侧边栏「**设置**」→ 找「**导出词表**」卡片（在既有「导出、备份与恢复」区里）

应看到：
1. **三个模式卡片**（互斥单选，选中带描边）
   - **A4 默写**：单词列与释义列分左右两组、各自从 1 编号 → 打印后可遮一半做双向默写
   - **中文词表**：Word 列留空（带 □），Meaning 填释义 → 练「看中文写单词」
   - **英文词表**：Word 填单词（带 □），Meaning 留空 → 练「看单词写释义」
2. 「**乱序导出**」开关
3. 主按钮「**导出 PDF 词表**」
4. 点按钮 → 弹**系统打印对话框** → 选打印机「**Microsoft Print to PDF**」或「**另存为 PDF**」→ 保存 → 得到 PDF

### 打印页要看什么

- **A4 竖版**，页边距约 12mm；顶部标题行 +「共 N 词 M 页 · 第 p/M 页」
- **双栏**，每栏都有表头（Word / Meaning）与行首 □
- 中文字体正常（微软雅黑），浅色条纹底纹保留
- **换一次模式再导一次**，三个 PDF 的差异应符合上面第 1 条

> ⚠️ 打印通道（iframe + `print()`）**没在真窗口点过**——如果点按钮没反应，就是我这条路径在 WebView2 里不通，告诉我我改走「生成文件后打开」路径。

## 六、已知限制

| 项 | 说明 |
|---|---|
| 打印通道未真窗口实测 | iframe + `print()` 是本环境唯一零依赖路径；弹不出就换方案（concern 1） |
| 导出入口在设置页 | 不在生词本页（生词本原本没有导出入口，搬过去会重复）。若你希望在生词本里，我下一轮迁（concern 2） |
| A4 模式左右是「同批词」 | 左 Word 1..15 / 右 Meaning 1..15（按「遮一半双向默写」理解）；若你想要左右两批互不重叠，改一处即可（concern 3） |
| 乱序每次不同 | 时间种子，同一份数据两次导出顺序不同；要可复现我加种子参数（concern 4） |
| M6 样式未打磨 | 记录/设置页复用既有卡片与按钮类，观感一般（DB-M6-1） |
| 「上次位置」是屏幕位置 | 显示「第 N 屏」（滚动像素换算），非精确到句（DB-M6-3） |
