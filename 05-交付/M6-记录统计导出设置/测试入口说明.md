## 二、M6 实测清单（8~10 分钟）

### 1. 记录页（`/records`）

侧边栏「**记录**」→ 应看到：

- **统计卡**：已读篇数 / 已完成 / 总时长 / 笔记 / 生词 / 复习次数 + 「连续阅读 N 天」
- **时间线**：按最近阅读倒序，每行「标题 / 已完成或未完成 / 用时 / 上次位置 / 日期」

### 2. 设置页（`/settings`）

- **主题三档**：浅色 / 深色 / 跟随系统 —— 点「深色」应立即变暗，**重启后仍是深色**
- **复习间隔**：只显示 `1 / 3 / 7 / 14`，**没有**可编辑控件（设计如此）
- **备份**：点「备份」→ 应生成 `.db` + 同名 `.json` 元信息
- **恢复**：选刚备份的 `.db` → 应提示「已先备份当前库」再恢复
- **关于**：版本 `v0.1.0`、MIT、免责声明、内容来源说明四项
- **重新查看引导**：能再次弹出三屏引导

### 3. 首次引导（`/`）

设置页点「重新查看引导」→ 应看到三屏（① 点句子看解析 ② 点单词看本句意思 ③ 可以导入自己的材料），可跳过。跳过后再进不重复弹（`guide_shown=1` 已写库）。

### 4. 生词导出

生词本页 → 导出 → 应生成 `judou-vocab-YYYYMMDD.html`，**双击能离线打开**、样式正常、每个词一张卡（词/音标/释义/搭配/例句/来源句/标签）。

### 5. 空态（可选，30 秒）

如果某处数据为空（如「我导入的」没有文章），应看到「下一步做什么」的引导文字，而不是一片空白。
