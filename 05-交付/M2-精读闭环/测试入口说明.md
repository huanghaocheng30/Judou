## 二、最小实测顺序（按这个顺序走，每步 1 分钟）

### 1. 打开文库 → 任一篇

应看到文章列表（按来源分组）与 12 篇文章。随便点一篇进入精读页。

### 2. 点一句话 → 看右栏解析卡

- 宽窗口（≥1100px）应出现**右侧栏**，正文不变形、不被遮住。
- 卡片顶部应先重述**你刚点的那句原文**。
- 六段顺序固定：①翻译 ②主干与成分划分 ③从句与语法点 ④重点短语 ⑤易错点 ⑥段落作用；**①②默认展开，③~⑥默认折叠**。
- ②段里符号应变成样式：`【主语】` 蓝底、`_谓语_` 下划线、`~表语~` 波浪线、`{从句}` 留花括号、`(短语)` 留圆括号 —— **文字一个都不能少**。

### 3. 点一个词 → 看词卡三态（这是 M2 最容易被挑的地方）

在同一篇里分别点这三个样本词，应出现三种不同形态：

| 点这个词 | 应看到 |
|---|---|
| `provoke` | 显示**语境义**（这篇里它是什么意思） |
| `teenagers` | 标题写「**词义（通用）**」+ 通用释义（这篇没有专门解析，只有词库） |
| `the` | 「**暂无预置解析**」（既无语境义也无词库条目），**不能是空白卡** |

- 有「更多」按钮的词，点开才出现词根/近义/易混（默认折叠）。
- 词卡里**没有收藏按钮**（收藏是 M3，故意不放，连灰按钮都不放）。

### 4. 点词不该弹句子卡

点词 → 只出词卡，句子卡应消失/不出现。点词与词之间的**空白**或句子末尾 → 才出句子卡。

### 5. 选词填空篇 → 点空号 26~35

换到选词填空那篇（15 选 10），点正文里的空号 → 三段：「正确答案（词 + 词库字母）/ 为什么是它 / 易错与排除」，易错项应**逐条一行**（不是挤成一坨）。

### 6. 题目区 → 折叠与答案

- 题目默认折叠，展开后每题有「显示答案」。
- 点「显示答案」→ **只显示答案字母 + 对应选项文字**；**不判对错、不计分、不出现红绿对错色**。
- 选项**点了没反应**（本版不做作答）。
- 长篇阅读第 2 套第 38 题应显示「**本题无预置答案**」（内容包本身缺答案，如实显示）。

### 7. 写笔记（句子 3 栏 + 词 3 栏）——**修复包已让笔记在正文可见**

句子卡里应有「我的笔记」区，3 栏：翻译 / 语法 / 短语；词卡 3 栏：语境义 / 搭配 / 例句。

- 输入后**停手约 0.8 秒** → 应自动保存（有「保存中…」→ 无打扰）。
- 关掉窗口重开 → 内容还在。
- **清空三栏** → 显示「已清空」，重开不残留空行。

### 8. 换句不丢字（本包修过的一个真 bug）

在句子 A 里打一半字（**不等** 0.8 秒）→ 立刻点句子 B → 再点回 A：**刚才那半句应还在 A 里**（不能丢，也不能跑到 B 去）。

### 9. 窗口拉窄 → 抽屉（**Esc 已在修复包里做对，见 §零**）

把窗口宽度拉到 <1100px：

- 右栏应变成**底部抽屉**，高度**不超过屏幕 55%**。
- 抽屉可拖动调整高度（拖不动就用键盘，或用 Esc 关）。
- **Esc 能关**，关后回到正文原位置。
- 两档下同一句的解析内容应一致、笔记也都正常。

## 三、重点判据（这几条最容易出问题，请重点看）

1. **符号零丢字**：②段的句子去掉标记符后，字要一个不少（`【】{}()` 这些括号要保留显示）。
2. **词卡三态区分**：`teenagers` 必须显式写「词义（通用）」，不能和 `provoke` 的语境义混在一起；`the` 不能空白。
3. **点词不误触**：点词只出词卡。
4. **笔记不丢**：换句/关面板都不丢；失败时草稿要留着并有重试提示（失败路径不易手工触发，属机器证据覆盖）。
5. **不判分**：题目区任何地方都不出现「正确/错误」的对错语义色。
