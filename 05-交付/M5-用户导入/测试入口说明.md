## 二、最小实测顺序

### 1. 粘贴导入（核心）

侧边栏「**导入**」→ 应看到文本框（不再是占位页）。

粘贴这段测试文本：

```
Reading is a habit that builds over time. Many people read slowly at first.

Practice makes the habit stronger every single day. Keep a notebook beside you while you read.
```

点「**解析预览**」→ 应看到：

- **统计**：2 段 / 4 句 / 30 词
- **段落列表**：2 段，每段前有勾选框（可剔除）

### 2. 剔段 + 改标题（预览页可编辑）

- 取消勾选第 2 段 → 统计应变 **1 段 / 2 句 / 15 词**
- 改标题为「我的测试文章」
- 题型选「四级」或「其他」，年份填 2024

### 3. 确认导入 → 跳转

点「**确认导入**」→ 应**自动跳到精读页**（`#/article/<id>`），标题显示「我的测试文章」。

### 4. 降级精读（这是导入文章的关键特性）

在刚导入的文章里：

- **点句子** → 句子卡应显示「**该篇无预置解析，可写笔记**」（不是空白、不是报错）
- **点词** → 词卡显示「**暂无预置解析**」，但「**加入生词本**」按钮**在**（能收藏）
- **写笔记** → 能存住

> 为什么没有解析：导入的文章只有原文，没有人工标注的语法解析。这是设计（04 §6.4），不是 bug。

### 5. 文章库分组

回「文章库」→ 应有「**内置**」与「**我导入的**」两个 Tab：

- 「内置」12 篇（真题）不变
- 「我导入的」1 篇（你刚导的）

### 6. 错误交互（可选，20 秒）

- 粘贴一段**超过 2 万字**的文本 → 点解析 → 应提示「**正文超过 2 万字符，请分段导入**」，且**预览状态不丢**
- 同一篇再导入一次 → 应提示「**这篇已导入过**」

M5 改了 `commands.rs`（`has_analysis` 真实查询）、`SentenceCard.tsx`（降级文案）、`api.ts`/`types.ts`。请顺手确认：

## 四、重点判据（最容易出问题）

1. **统计数字对**：2 段 / 4 句 / 30 词（我给的测试文本）
2. **剔段后统计跟着变**
3. **导入后自动跳转**到精读页
4. **导入文章显示「该篇无预置解析，可写笔记」**——而**内置文章必须仍有解析**（两者对比看最清楚）
5. **文章库两个 Tab 分类正确**
6. **导入文章的词仍能收藏**

## 六、你要知道的已知限制

| 项 | 说明 |
|---|---|
| **中文/emoji 文本未实测** | 偏移量用 UTF-16 code unit（已用 `"I love 😀 fun."` 单测证 14 单位），但**真机没跑过中文文章**。若你粘中文散文可能切句不准（句号是全角「。」，当前切句只认 `.?!`）→ **建议先只粘英文** |
| **只支持粘贴**，不支持选文件 | 文件选择器需要处理路径限域与 `basename` 化，归 M6 |
| **不做 PDF / DOCX / OCR** | 同上 |
| **不做自动生成解析** | 导入文章就是无解析（04 §6.4 的降级设计） |
| **每次导入都是新文章** | 同一篇再导会报「已导入过」（`source_key` 撞 UNIQUE），不做覆盖重导入 |
| ~~无真 WebView2 读数~~ **已解除（TP-修复6）** | 当时 `tauri dev` 起不来（真因是 bin 歧义，非缺 MSVC），M5 验收走 Chromium + 真组件 + IPC 模拟层。现已能真机起窗 → **请在真机上重点看** §二.4（降级精读）与 §三 第一行（内置文章仍有解析） |
| `commit_import` 采信前端 `stats` | 未与真实行数交叉校验（债务 D-1，M6 前补护栏） |

## 七、本版不做

文件选择器 / 拖拽、PDF / DOCX / OCR、自动翻译或自动生成解析、导入后编辑原文、去广告正文提取（用户自己在预览页剔段）。
