## 二、U2 · 词笔记圆点（根因不是逻辑，是 CSS 几何）

**根因**：`radial-gradient(circle 1.6px at center bottom)` 的**圆心落在背景绘制区的底边**——圆的下半被裁掉，只剩上半圆（实测 bbox 高 **1.33px**），又贴在字母脚底板下面 → 视觉上等于「没画」。

**修法**：`app.css` 改 **2 个数值**——圆心抬到 `center 2.4px`、条带高 `4.5px` → 实测 bbox **3.33×3.17** = 完整圆点。**零 TS/TSX 改动**。

**判据区分力自证（重要）**：同一套判据，注入改前旧 CSS → **8 FAIL**；新 CSS → **8 PASS**。这说明判据**真能抓住这个 bug**，不是空过。
