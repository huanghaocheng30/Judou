## 二、最小实测顺序

### 1. 标记完成（这是新入口）

进任一篇（如 *Why We Are So Proud to Say We're Busy*）→ 拉到正文末尾（题目之后）→ 应有「**完成本篇**」按钮。

- 点它 → 文案变「**已加入复习计划（明天到期）**」
- **再点一次** → 文案仍是「已在复习计划中（…）」，**不应**重排到更远的日子（幂等）

### 2. 今日待复习

侧边栏「**复习**」→ 应看到：
- 该篇文章一行，带到期标签（「明天」或「逾期 N 天」）与「**第 1/4 次**」
- 侧边栏「复习」项上应有**角标数字** = 到期篇数

> 想立刻看到「今天到期」，可手工改库：`UPDATE review_plan SET next_review_at = date('now','localtime')`。不改也行——明天它自己会到期。

### 3. 复习模式（本包最值得验的一条）

点条目「**开始复习**」→ 进精读页，URL 带 `?mode=review`：

- 正文**句子末尾的「析」角标应不可见**（写过笔记的也不可见）
- **词上不应有笔记圆点**
- 点词 → 词卡弹出，但**「加入生词本」按钮不应显示**
- 页面底部应是「**完成复习**」/「**还需再看**」，**不是**「完成本篇」

> 目的：复习时别被自己的笔记提示答案。

### 4. 顺延

点「**完成复习**」→ 回到复习页：
- 该篇**不在今天的到期列表**里了（顺延到 3 天后）
- 切「按掌握状态」等轴不受影响
- 若点「**还需再看**」→ 明天再到期、**档位不变**（仍是「第 N/4 次」）

### 5. 四档走完 → 不再提醒 + 可重启

一路点到第 4 次完成 → 该篇 `status='done'`，**不再出现在到期列表**，而是进「**已完成**」区，并显示**文章标题**（不是「文章 #3」）。

- 已完成区每条有「**重新加入复习**」→ 点它 → 回到第 1 档、明天到期

### 6. 空态

把到期清空后进复习页 → 应显示空态（无到期 / 今日已完成两种文案 + 「去文章库」按钮）。

## 四、重点判据（最容易出问题）

1. **幂等**：重复点「完成本篇」不重置日期
2. **顺延档位**：完成 1 次 → 3 天后；2 次 → 7 天；3 次 → 14 天；4 次 → 不再提醒
3. **「还需再看」不前进**：只把下次推到明天，档位不变
4. **复习模式藏三件套**：角标 / 词圆点 / 生词按钮都不显示，但**节点仍在**（不是删了）
5. **已完成区显示文章标题**

## 六、你要知道的已知限制（都不影响上面的实测）

| 项 | 说明 |
|---|---|
| **跨午夜** | 「今天」由页面打开时现算（`localToday()`），**页面挂着跨过午夜不会自动刷新**。重新进页面即正确。CDP 用注入 Date 验证了两态，真机跨午夜未验 |
| **`restart/get_review_plan` 的 title 为空串** | 只有「已完成」区（走 `list_review_plans`）显示标题；另两个命令不带 title。当前无消费方读它，谁将来要显示谁加 JOIN |
| **M2/M3 完整 CDP 套件未逐条重跑** | 本包只抽测（`data-sentence-id` 20 / `data-token-id` 350 / `data-vocab-state` 在位 / 题目答案 / 生词本 9 行）。故把上面 §三 列为**人工强制项** |
| `localToday` 定义在 `pages/Review.tsx` | 被 `Reader`/`Sidebar` 反向引用（页面导出非组件函数，轻微异味），功能正确；迁 `lib/` 会超本包改动面，登记债务 |
