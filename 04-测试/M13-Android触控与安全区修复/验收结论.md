## 五、构建链教训（已写入 `00-项目管理/Android环境搭建.md §十`）

`npx tauri android build` 在 symlink 步骤失败退出时会**清空 jniLibs 的 .so** 且**不复制 dist 到 assets** → APK 缺 so 静默闪退 / 白屏。
正确顺序：tauri CLI（忽略 symlink 报错）→ 手动 Copy .so → **手动 Copy `dist\*` 到 assets** → gradlew `-x rustBuildArm64Debug` → **装包前 zip 列表校验**。
